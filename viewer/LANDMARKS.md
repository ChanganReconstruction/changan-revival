# 十八景集中核验清单

当前按“先完成粗版、最后统一验收”推进，不将每个景点提交用户逐一确认。
“独立构造”不等于考古精确复原；城市生活场景也不应为了凑数再造一栋不存在的楼。
修正2已授权改造整体观感：旧田草色块改为连续自然底色，渠线基本保留。
本轮提高宫城主殿/仓院体量层级，街坊使用共享缓坡屋面变体和分区色组，不追加细部考据负担。

| 游览点 | 实际场景及当前核验项 | 证据边界 |
| --- | --- | --- |
| 国门明德 | 新专属门楼、六墩五门道；检查全厚净空和两侧城墙衔接 | 五门道及55.5×17.5米基址有据，楼身推定 |
| 天街纵目 | 朱雀街轴线、槐荫、两侧真实细沟与分级道路 | 艺术压缩，沟宽深不是测绘 |
| 横街广场 | 通行带、两侧槐荫、街亭与开敞界面 | 街亭和植树节奏为游览构图 |
| 龙尾含元 | 十一间主体、周匝副阶、两侧盘道和阙楼 | 柱网与改道依据见资料卡，尺度压缩 |
| 含元俯瞰 | 与上一项共用同一实体建筑，核对台地与城市空间 | 不为不同机位重复叠建模型 |
| 太液蓬莱 | 曲岸、单蓬莱堆山、岸廊、林木及水陆衔接 | 岛形和岸线艺术化，不套现代三岛园林 |
| 花萼龙池 | 两层长翼接偏置三层主楼、沉香亭、龙池、龙首末段 | 使用研究方案再描绘，不称原始发掘图复原 |
| 西市胡尘 | 九区铺栈、棚幔、货院、卸货岸与永安街段 | 市肆逐铺与货品位置推定 |
| 东市珍奇 | 更宽街巷、大铺货院、不同店幔与空间疏密 | 东西市差异为艺术组织，不冒充逐铺史实 |
| 雁塔登高 | 新楼阁式砖塔、逐层收分、四面开口及寺院留空 | 采用七层识别方案，武周层数有不同说法 |
| 小雁晨钟 | 新十五层密檐砖塔；首层高、上层紧密、不套住宅瓦顶 | 原十五层与今十三层分开；高度和刹顶推定 |
| 乐游青龙 | 原坡高地、寺院组群、钟鼓亭及望城空间 | 新昌坊高地意象，不称现存殿阁测绘复刻 |
| 靖善梵阁 | 礼制轴线、中殿、两庑、侧阁与抬升地基 | 大兴善寺意象，非唐代完整院图 |
| 坊门昼启 | 真实门道、侧置鼓楼、白昼开门状态 | 开合规则示意，门楼柱距艺术处理 |
| 巷曲井台 | 井口、提水架、槐树、石凳和巷曲净空 | 日常生活组合，不虚构具名宅邸史料 |
| 曲江流饮 | 双湾曲岸、坡岸、岛、临水建筑、栈道和黄渠末段 | 岸线、入口与上游省略均明确说明 |
| 金光驼影 | 西门、驼道、双峰驼队和驮包 | 静态商旅意象，未实现交通仿真 |
| 暮鼓夜禁 | 与坊门共用实体、夜间闭扇、灯窗和鼓楼 | 不因昼夜复制一套场景 |

另有麟德三殿四亭楼、丹凤门五门道，不作为新增导航数量冒充十八景扩容。
全部共用构件/材质及实例批次；没有为每个景点建立完整独立材质库。

## 本轮集中核验结果（2026-11-17）

- 完成全部 23 个导航机位，包括十八景；标准档全覆盖，精致档另查全城、含元、民居、兴庆、西市。
- 完成白昼 8 张无界面图和金色 3 张，覆盖全城、正俯视、民居、宫城、寺院、天街、山川和太阳。
- 63 项单元测试通过；两档各 42 项浏览器检查通过，页面错误为零。
- 日夜、巡游、108 坊点选、独立渲染比例、植被互斥覆盖、静止零重绘与阴影复用均通过。
- 首帧阴影与缓存帧分别记录；仍只验证软件 GPU 的正确性和几何成本，不承诺实体显卡 FPS。
- 水渠按最新意见保留，资料卡继续标出年代、入口推定和省略段；本轮不把未绘全程称作完整五渠。
