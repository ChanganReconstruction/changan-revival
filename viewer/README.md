# 长安 · 一城盛唐

独立的 Three.js 唐代长安浏览应用，采用低多边形几何、程序材质与实例化绘制。
年代意象为开元—天宝，不逐栋高精建模，不依赖原体素项目运行。

## 当前：整体观感改造（修正2）

以下为并入主仓库前的原型改造记录；截图和浏览器报告属于本地生成产物，不随源码提交。

- 民居增加实际宅地允许范围内的进深，低宅墙檐比例全城应用；不挪坊界或缩窄主街。
- 墙身与屋面坡度解耦，屋盖仅采用两档共享变体，不靠尖顶或整栋纵向拉伸制造体量。
- 街区采用有限的冷灰、暖灰、泥灰素壁色组，礼制建筑保留素壁衬朱木，颜色写入实例属性。
- 重点游览坊保留近景柱梁，背景只提交屋面、墙体和常驻立面贴图，贴图内表达柱窗节奏。
- 太极主殿、署院、仓场与门外侧院形成体量级差；含元前场分段铺地，两侧盘道及五门净空保留。
- 北部林苑改为不等树团，仍走原三层植被替换及四个共享实例网格。
- 取消城外田草棋盘，城内外地形与远景贴图共用连续低饱和色场；隐藏底座不再露出托盘边。
- 天空增加与方向光一致的太阳/月盘和克制光晕，降低远景雾密度，金色时段采用低太阳长影。

水渠基本布局和宽深层级保留，没有继续大改渠线。本轮体量、色组与林苑为艺术化构图，
不是新增历史测绘结论；[证据说明](<RESEARCH.md>)继续区分可靠关系与推定部分。

## 上一批：植被近中远互斥替换

## 上一批：花萼楼可替换独立方案

连续楼板、挖空檐圈、朱柱、窗棂和栏杆按材质合并为六组构件后进共享实例批次。

## 上一阶段：全城鸟瞰返工

针对全城重复、湖泊过简的反馈，上一轮以无界面全城鸟瞰为先，重建坊内规划与宫苑水系。
十八景和二十二个机位仍保留；布局参考原 voxel 项目，不承诺逐体素或考古级一比一复原。

- 住宅先切不等宽地块，再生成前铺、后宅与杂屋；不是把完整三合院平铺到每坊。
- 寺观、官署、府第各有三种拓扑，庭院与园圃作为禁止建房的实际空间预留。
- 屋顶朝向、高低和密度随地块变化；保留南坊门通往主巷的连接。
- 两市跨两坊合成完整井字街九区；北部重新组织服务院、仓场与苑地，去除复制坊阵列。
- 当时含元采用十三间简化原型；现已分开主体与副阶，详见本轮说明。
- 太液为单蓬莱异形堆山岛；龙池与曲江使用手绘非对称曲岸、岸坡和临水建筑。
- 连续原坡与贴地道路配合坊内整地，远处地形、路面、院坪留有深度精度余量。

- 保留 108 坊位、三重城、朱雀街、两市、宫城、两座雁塔和曲江的城市骨架。
- 密居采用偏巷与退进宅列；崇仁作坊有店棚货院；永兴府第采用大院、附院和阁楼。

## 性能边界

- 普通建筑没有逐栋 Mesh，使用共享原型、共享材质和 InstancedMesh。
- 原型背景部分小于 180 三角面，近景附加柱梁小于 260 面；阁楼与特殊地标另计。
- 四面门窗只需八个三角面并始终保留，夜间窗洞用共享发光图，不开启大量动态灯光。
- 主体按 800、柱梁按 128 世界单位分块；近景距离为流畅 60、标准 95、精致 160。
- 相同原型构件跨屋顶类型共用几何。树冠采用二十面体；背景不堆叠窗棂与斗拱小盒子。
- 静止后暂停 GPU 重绘；阴影只在时辰、画质或量化观察范围改变时重建。
- 常规档直接绘制到屏幕；仅精致档启用环境遮蔽与离屏后处理；流畅档关闭阴影。
- 软件 GPU 和手机默认流畅，实体显卡桌面默认标准。软件测试不能证明实体显卡帧率。
- 性能面板的调用与三角面计数包括当前帧的阴影/后处理；静止时显示暂停，不冒充高 FPS。
