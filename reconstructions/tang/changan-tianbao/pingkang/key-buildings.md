# 平康坊重点建筑：本址记载、参照图版与证据边界

[返回平康坊总页](README.md) · [证据索引 CSV](evidence-index.csv) · [通用史料手册](../handbook/README.md)

本文只处理三处重点对象：**菩提寺、李林甫宅（含月堂）、嘉猷观**。每处先列本址文字，再列可用的同城或同类图版，最后说明这些材料能证明什么、不能证明什么。所有尺寸凡属参照建筑，均标明“参照值”，不写成平康坊本址实测。

## 读法：三类材料不能互相冒充

| 材料类型 | 能回答 | 不能回答 |
| --- | --- | --- |
| 平康坊本址文字（《长安志》《寺塔记》《开天传信记》等） | 谁住在哪里、某屋在另一屋的哪个方向、哪面墙有画、钟楼为何在西 | 开间、进深、柱高、屋顶形式、院落边界、准确坐标 |
| 同城遗址平面（西明寺、安仁坊宅邸） | 同期长安寺院与高等级宅第可能的院落组织、回廊宽度、殿址间距、散水做法 | 平康坊某寺某宅的平面；建筑面积与房间数 |
| 同类单体木构（南禅寺大殿） | 唐代佛殿的开间比例、柱高、斗栱层数、屋面举折 | 天宝时期平康坊某殿的原状；宅堂与佛殿的功能差异 |

因此，下文给出的图版与数字用于**控制比例和院落节奏**，不是把参照建筑改个名字就当作平康坊原貌。

## 一、菩提寺

### 1.1 本址文字

- **位置与沿革。**《长安志》卷八平康坊条：“南门之东菩提寺。”同条载其隋开皇二年（582）立，唐大中六年（852）改称保唐寺。[PK-S02](README.md#pk-s02)
- **称谓。**段成式《寺塔记》称“平康坊菩萨寺”，当即菩提寺；两种称谓并记，不据名称差异推断为两寺。[PK-S03](README.md#pk-s03)
- **钟楼方位。**《寺塔记》：“寺之制度钟楼在东，唯此寺缘李右座林甫宅在东，故建钟楼于西。”这是**钟楼在寺西、李宅在寺东**的相对关系，也是寺院布局迁就邻宅的唐人解释。[PK-S03](README.md#pk-s03)
- **殿与食堂。**《寺塔记》记佛殿、食堂及壁画：佛殿东西障日与诸柱上旧有郑法士画，开元中移入大佛殿内槽北壁；食堂东壁有吴道玄《智度论色偈变》。所记是画的位置与作者，不是殿身尺度。[PK-S03](README.md#pk-s03)
- **考古。**平康坊遗址历年出陶俑、窑址、鎏金银茶托等，尚未见可归到菩提寺殿址的柱础、台基或平面图。[PK-S08](README.md#pk-s08)

### 1.2 可用参照：西明寺东部院落

西明寺在延康坊西南隅，占西南四分之一坊，显庆元年（656）立、显庆三年（658）完工。1985、1992、1993 年三次发掘，东部最东的院落南部为附属院落与中央夹道，北部为东、西、南三面回廊围合的**主院落，含三重殿址、三进庭院**。遗址总平面见《青龙寺与西明寺》第123页图66。[PK-S09](README.md#pk-s09)

可直接查用的参照值：

| 项目 | 数值 | 用法 |
| --- | --- | --- |
| 回廊台基宽（含包砖） | 多为 **6.74 米**；西回廊 10.44 米，东回廊北段 12.5 米 | 寺院回廊的尺度感；不是菩提寺回廊宽度 |
| 1、2 号殿址南北中轴间距 | **60.28 米**，合 41 步（205 尺） | 院落进深的节奏；不是菩提寺殿距 |
| 推定营造尺 | **294 毫米** | 与大明宫含元殿、麟德殿一致；用于理解同期官方营造尺度 |
| 遗存状态 | 仅存夯土台基、包砖、散水、水井；柱础柱洞基本无存 | 不能据西明寺复原柱网，更不能替菩提寺补柱网 |

**限度：** 西明寺是皇家敕建大寺，菩提寺等级、占地与院落数均不同。西明寺只能支持“回廊围合、三进庭院、殿址居中”这一类形制想象，不能证明菩提寺也有三进院或同样殿距。

### 1.3 可用参照：南禅寺大殿

南禅寺大殿建中三年（782）重建，面阔、进深各三间，平面近方，单檐歇山顶，举折平缓。2022 年研究给出的比例数据：[PK-S10](README.md#pk-s10)

| 项目 | 数值 | 用法 |
| --- | --- | --- |
| 明间／次间 | 16.5 尺／11 尺（营造尺 300 毫米，约 4.95／3.30 米） | 三开间佛殿的开间比例 |
| 平柱高 | 13 尺（约 3.90 米） | 柱高与明间的比例 |
| 斗栱 | 五铺作双杪偷心造，无补间铺作 | 中晚唐殿式的斗栱密度参照 |
| 总举折比 | **1:2.67**（举高:前后橑檐间距） | 屋面坡度；比佛光寺东大殿 1:2.23 平缓 |
| 佛坛高 | 720 毫米（2.4 尺） | 像设基座高度参照 |

**限度：** 南禅寺晚于天宝三十二年，且是五台山的地方佛殿，不是长安寺院；其开间与举折只能用于控制“唐风”比例，不能写成菩提寺大佛殿的尺寸。

### 1.4 菩提寺可交付到什么程度

- **可以交付：** 寺在坊南门东、李宅在寺东；钟楼位于寺西；寺内有佛殿、食堂，二者有壁画记载；寺院为南门内东侧的一组院落。
- **可以参照：** 回廊围合、三进院落的组织方式；三开间佛殿的开间、柱高与屋面举折。
- **不能交付：** 寺界、院数、殿身面阔进深、钟楼层数与高度、食堂与大佛殿的相对位置、壁画原貌。上述各项在现有材料中没有本址依据。

## 二、李林甫宅与月堂

### 2.1 本址文字

- **位置。**《长安志》卷八：“东南隅，右相李林甫宅。本尚书左仆射、卫国公李靖宅。”同条又载李林甫奏分宅东南隅为嘉猷观。[PK-S02](README.md#pk-s02)
- **与寺的关系。**《寺塔记》以“李右座林甫宅在东”解释菩提寺钟楼为何置于西，可证李宅在寺东。[PK-S03](README.md#pk-s03)
- **南街旧宅。**《开天传信记》：“平康坊南街废蛮院，即李林甫旧宅也。”此条称“南街”，与《长安志》“东南隅”并见；二者可相容，也可指不同时期的门户或记载口径，现有材料不足以合成精确宅界。[PK-S06](README.md#pk-s06)
- **月堂。**《开天传信记》：“林甫于正堂后别创一堂，制度弯曲，有却月之形，名曰月堂。木土秀丽精巧，当时莫俦也。”[PK-S06](README.md#pk-s06)
- **异文。**《太平广记》卷三百六十二引《开天传信记》作“名曰偃月堂。土木华丽，剞劂精巧，当时莫俦也”；《侯鲭录》等又作“却月堂”。月堂、偃月堂、却月堂应并列记录，不能只取一名而隐去其余。[PK-S11](README.md#pk-s11)
- **晚年宅第。**《旧唐书·李林甫传》记其“重扃复壁，络板甃石”，又记“发丧于平康坊之第”。这能说明宅第防卫严密，不能据此画地下通道、密室或内院平面。[PK-S04](README.md#pk-s04)

### 2.2 “却月之形”能读到什么

“偃月”“却月”都指半月形。“制度弯曲”与“有却月之形”最自然的理解是**堂的平面或整体轮廓呈弧形**，但原文没有说明弯曲的是台基、墙体、屋面还是平面，也没有给弧度、面阔或进深。

可以写入建模说明的，只有一句：**月堂位于正堂之后，平面或轮廓可能呈半月形，具体形制未知。** 不应把“却月”直接翻成曲面屋顶，也不应据“月堂思计”一类后世叙述补出室内陈设。

### 2.3 可用参照：安仁坊宅邸

2017 年西安市文物保护考古研究院在安仁坊西南隅发掘近 6000 平方米，发现 **10 个房址**，大致分布在东西相连的几个院落内，排列有序，**有的以长廊连接**；并见散水、排水沟。安仁坊在《长安志》中称“皆是亲王外家，甲第并列，京城美之”。[PK-S12](README.md#pk-s12)

**限度：** 安仁坊宅邸的完整发掘平面尚未公开发表，现有图多为展示馆设计方的遗址分布图与现场照片。它能支持“高等级宅第可由多院组成、院间以长廊连接、院内有散水与排水”这一层级，不能给出李宅的院数、院宽或正堂尺寸。

### 2.4 可用参照：南禅寺大殿

李宅正堂不是佛殿，不能直接套用佛殿形制。南禅寺的可取处只在**开间与柱高的比例、屋面举折**，且须明确写成“宅堂按同期木构比例控制”，不能写成“李宅正堂仿南禅寺”。唐《营缮令》三品以上堂舍“五间九架”是元和十二年（817）奏文所引，晚于天宝，只能作等级上限的背景，不能反推李林甫宅正堂必为五间九架。

### 2.5 李宅可交付到什么程度

- **可以交付：** 宅在坊东南隅、菩提寺之东；宅内有正堂，正堂之后另有月堂；月堂名称与“半月形”描述有三种写法；宅东南部后来析出嘉猷观。
- **可以参照：** 多院并列、长廊连接、散水排水的宅第组织；三开间木构的开间与柱高比例。
- **不能交付：** 宅界、宅门位置与朝向、正堂面阔进深、月堂平面与屋面、侧房与廊庑布置、院内陈设。现有材料不足以画出可信的宅内平面。

## 三、嘉猷观

### 3.1 本址文字

- **析宅置观。**《长安志》卷八：“李林甫奏，分其宅东南隅，立为嘉猷观。观中有精思院，王维、郑虔、吴道子皆有画壁。”[PK-S02](README.md#pk-s02)
- **赐额。**《唐两京城坊考》卷三平康坊条记玄宗赐金字额；原卷此条与李穆宅条相接，可帮助定位，但不能据此定观界。[PK-S02](README.md#pk-s02)
- **沿革异文。**同书又载“林甫死，后改为道士观，择道术者居之”。此语与前述“置观”“赐额”并见，是先有私观还是先有宅、何时改额，需核对原卷与《唐会要》相关条；本文不强行编年。[PK-S02](README.md#pk-s02)、[PK-S07](README.md#pk-s07)
- **建置年。**赐额与置观的确年尚未查到原始纪年，不能写成“天宝某载建”。

### 3.2 可交付到什么程度

- **可以交付：** 嘉猷观由李林甫宅东南部析出；观内有精思院；精思院有王维、郑虔、吴道子壁画；后曾改由道士居住。
- **不能交付：** 观的独立院界、山门位置、殿宇数量、精思院在观内的位置、匾额形制、壁画题材与画面。现存材料只有文字，没有本址平面或立面。

## 五、仍需查证的事项

1. 菩提寺的寺界、殿址与食堂位置：查《隋唐长安城遗址考古资料编》所收平康坊条目，以及1957年以来平康坊发掘的原始简报，确认有无可归入寺址的夯土、砖基或柱础。
2. 李宅与嘉猷观的分界：核对《长安志》《唐两京城坊考》《唐会要》各本文字，确认“分其宅东南隅”是析出宅东南部还是另占坊角。
3. 嘉猷观置观与赐额年：查《唐会要》卷五十、《册府元龟》及唐宋道观碑记，找到原始纪年再编年。
4. 月堂形制：继续检索唐宋笔记、方志与《李林甫》相关史料，看是否有“偃月堂”平面或图像的进一步描述；在找到之前，只保留“正堂后、半月形”两条。
5. 安仁坊宅邸正式报告：待发掘报告或简报公布后，替换现在的展示馆示意图，并核对其院数、房址编号与尺寸。
