## 平面、台基与首层

以塔心 `(0,0)` 为定位基准，塔台、砖身和塔顶均同心。四面正对项目坐标轴；**不要把正面旋转四次来做四立面**。台基约23.38米见方、塔身脚11.38米见方取[公开现状资料转述](sources.md#jf-s02)；台面标高本版取 `3.20`，另一资料作约 `3.5`，两者都保留，建模时以一个参数切换。1965年整修涉及台基范围与券洞，采用现代尺寸是为补足本版几何，不认证现状各皮砖属于唐代。

| --- | --- | --- |

## 十五级塔身与密檐

[逐级 CSV](pagoda-levels.csv) 即本版尺寸底稿，单位米。`Z=0` 为本版院面，`body_base_z` 为该级起点，`eave_top_z` 为该级檐部上口，也是下一级的起点。两个 `body_side` 尺寸均指**砖身外皮的方形边长**（不含檐）：每级内作线性收分，逐级改变收分率。第1级底边是现状转述值；各檐口标高由一张正面近照的檐口唇缘像素间距按约 `0.16 m/px` 反算，再以 `43.395` 米总高闭合，故是**照片近似，不是实测**；未做透视校正，边长与挑出仍属参数化推定。第6级起收分加大，是为了贴合照片上部轮廓转陡的趋势，不是逐级实测到的折点。

1. **逐级放样。** 每级按方形出檐，不按圆形处理；`eave_projection` 是相对于该级 `body_side_top` 的单边最大水平挑出，最大檐宽 = `body_side_top + 2 × eave_projection`。局部砖身维持收分，不加木构仿形或瓦垄。
2. **檐口剖面。** `eave_band_height` 自 `eave_top_z` 向下量。设檐带底至顶的归一化节点 `(高度比例, 挑出比例)` 为 `(0,0) → (0.28,0.26) → (0.53,0.53) → (0.76,0.80) → (0.90,1.00) → (0.96,1.00) → (1.00,0)`。起点接檐带底处的收分墙皮，其余节点的水平坐标以 `body_side_top / 2` 为基线加上相应挑出量；相邻节点间按砖叠涩出挑，上部短斜面收回砖身。檐带最下两道表现为菱角牙子；近景按可辨砖层调整，不把此节点图当成原塔精测砖皮。砖缝可先用实体与贴图混合表达；本版面砖模数暂用 `0.32×0.08`（长×皮高，含缝），非唐砖规格认定。
3. **券口与窗台。** 第2–13级南北面中线设置半圆拱顶券窗。表内 `opening_sill_z` 是洞口下沿，`opening_height` 是净总高，起券高为洞口下沿＋净总高−净宽的一半。券窗可做 `0.65` 深的暗凹以表现外观，不据此定真实贯入深度。窗左右各做低短砖叠涩台，本版每段宽 `0.60`、高 `0.16`、出挑 `0.16`，靠券口留 `0.15` 缝；东西面不加对应假窗。第14、15级位置失传，本版沿用南北小券窗作为延续推定。
4. **明确实际截面与推定截面。** 第13级上口本版取 `Z=43.60`，是照片上第13级檐口唇缘的读数，也是与本版总高 `43.6` 米（唇缘量法）相合的比例锚点；原报道的 `43.395` 米为1989年另一量法，两者不可混用。本版在该标高接续第14、15级与塔顶完整轮廓，不做残顶或后补封顶；第14–15级的层高、边长与券窗均为碑图示意下的延续推定。

## 塔顶与塔刹

十五级檐顶取 `Z=46.50`。本版用方形浅斜砖顶，从该处边长 `4.00` 收至 `Z=47.40` 的中央 `1.60` 米见方小平台；平台以上用素面刹座、逐级缩小的相轮和收尖轮廓。不采用现状平截顶作为唐代塔顶。

| 标高（米） | 本版采用几何 |
| --- | --- |
| `47.40–47.90` | 方座边长从 `1.60` 收至 `1.28`。 |
| `47.90–48.50` | 圆形刹身最大径 `1.03`，向上收至 `0.52`。 |
| `48.50–49.80` | 以直径 `0.25` 刹杆串五道简素圆轮；中心标高取 `48.62 / 48.86 / 49.10 / 49.34 / 49.58`，径 `0.90 / 0.82 / 0.74 / 0.66 / 0.58`；每轮厚 `0.11`。 |
| `49.80–50.55` | 上端过渡为最大径 `0.54` 的小型收尖宝珠，尖顶 `Z=50.55`。 |

**整段属可替换的推定方案。** 五轮数、刹的形制、材料和本版总高 `50.55` 米均未获原塔直接证据；`50.55` 是在“十五级檐顶 `46.50`”这一照片近似值上叠加的几何，不是对原塔总高的独立论证（文献另记原塔约 `45` 米、现存 `43.395` 米，量法不同，不可直接相减）。无须给这版刹座定金属或石材的历史材质。色彩先用较暗的素色，与暖灰砖身分开；不做明显新漆金顶。区分 `14–15级`、`斜顶` 和 `刹`，若后续找到资料可各自换形。

## 副阶（JF-06，可切换）

台基 `23.38` 米见方而塔身仅 `11.38` 米，四边各余约 `6` 米，正容一圈副阶。北宋政和六年（1116）李壄《大荐福寺重修塔记》记塔外“周徊副屋”残损后“悉皆修完”，张礼《游城南记》又记金末“塔之缠腰”废尽，可知**至迟北宋已有、金末已毁**。本版据此给出一圈可开关的副阶：五间、进深 `2.4` 米、檐口约 `7.5` 米，柱网与柱础全按灰模，形制参照盛唐五间殿堂及大雁塔门楣线刻的单栱素枋、人字栱。**它只有后世本址文献，不能证明天宝年间存在，默认方案不启用**；启用时在说明中必须写“1116年碑所见”，不得写成750年实证。细部见[单体卡 JF-06](buildings.md#jf-06-塔副阶可切换)。



## 近景取材与年代排除

砖面明暗以砌体、叠涩投影及券洞深度为主；踏步用中性灰石，台面用低对比素砖，不套现代广场铺装。现状照片看构造与光影，不照抄当前斑驳分布。排除明代题刻、震裂残顶、修缮铁箍、避雷针与现代楼梯；不从现状受损推断750年的原色或砖缝填料。[JF-S02](sources.md#jf-s02)、[JF-S03](sources.md#jf-s03)
