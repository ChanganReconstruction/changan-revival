# 礼制与纪念建筑

| 条目 | 所见材料与限度 |
| --- | --- |
| **RT-01 佛塔** | 《长安志》卷八大慈恩寺条记西院浮图及重修线索；遗产地图提供大雁塔、小雁塔等的点位 [S24](sources.md#s24)。现状含历史变化，不能仅据现代照片确定天宝塔身、层数和塔刹。 |
| **RT-02 经幢与刻经** | 何岁利西市研究图十八记录一件八棱刻经石件，通高117厘米 [S13](sources.md#s13)。可核断面和刻面，年代、原始立置及缺失部件须另证。 |
| **RT-03 祠庙** | 《长安志》坊条有祠、庙、寺、观的名称与迁改线索 [S07](sources.md#s07)、[S12](sources.md#s12)。机构名称与仪式不等于建筑平面。 |
| **RT-04 圜丘郊坛** | 隋唐长安圜丘发掘见四层圆坛；外围遗存及燎坛等辨认另有考古和礼书证据 [S25](sources.md#s25)。坛体测量、仪程和礼器陈设应分别引用，并非所有祭坛皆此形制。 |
