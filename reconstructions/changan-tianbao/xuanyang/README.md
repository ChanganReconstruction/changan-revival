## 本坊结论摘要

- **位置**：宣阳坊属万年县，在朱雀门街东第三街（即皇城东第一街）街东从北第七坊。西界启夏门街，隔街对崇义坊；北邻平康坊；南邻亲仁坊；东隔街即东市。北当大明宫兴安门、南当启夏门，说的是这条南北街的轴线，不是宣阳坊本身紧邻两门。[XY-S01](#xy-s01)、[XY-S02](#xy-s02)
- **坊界**：文献只直接给出“皇城左右共七十四坊……广各六百五十步”，即东西六百五十步；南北三百五十步是参照同街平康坊及皇城以南九坊的绘图参数，不是本坊实测。按 1 步≈1.47 米折算约 **955.5×514.5 米**。另有 1022×544 米说，出自二手论文且与“尚未直接发掘”自相矛盾，只作 C 级并列。[XY-S03](#xy-s03)、[XY-S14](#xy-s14)
- **门街**：东、西、南、北四门均有门位记载，坊内有十字街。门址、街宽、墙基均未在本坊发掘；图上四门居中、十字街正交、墙厚 3.5 米、街宽 15 米，都是示意。[XY-S01](#xy-s01)、[XY-S02](#xy-s02)、[XY-S17](#xy-s17)
- **东南隅**：万年县廨。县门屋为宇文恺所造；永隆二年（681）太平公主下嫁薛绍，于县廨设婚席。天宝时万年县仍治此，属于本期可用对象。[XY-S01](#xy-s01)、[XY-S02](#xy-s02)
- **西南隅**：净域寺。隋开皇五年（585）立，恭帝禅位后止此寺并卒；寺本太穆皇后宅之说见于《酉阳杂俎》。天宝初独孤明宅与寺相近。寺院在 750 年存续较可能，但院界、院数、塔位均无考。[XY-S01](#xy-s01)、[XY-S02](#xy-s02)、[XY-S08](#xy-s08)
- **宅第**：东北隅郭元振宅；十字街西北李诲宅；十字街东之北李乂宅及次西李衮、郑惟忠宅；西门之北韦巨源宅及宅东刘希进、杨务廉宅、隔巷韦叔夏、单思远宅；西门之南高仙芝宅；南门之西窦毅宅、归宁院、杞公庙；东门之北李济物宅。这些方位记载多属 8 世纪初，750 年是否仍为原宅主所有，除高仙芝、杨国忠、虢国夫人外均不确，图上以 `†` 标待核。
- **诸杨宅**：《新唐书》称“虢国居宣阳坊左，国忠在其南”，《唐两京城坊考》同。虢国宅本开元中虢国夫人杨氏宅，天宝末为杨国忠势力核心；安禄山入长安后取为京兆尹府，后为郭暧宅，9 世纪前叶立奉慈寺。750 年图上只画“相对位置待核”的示意区，不画院界。[XY-S02](#xy-s02)、[XY-S04](#xy-s04)、[XY-S08](#xy-s08)
- **异期与待核**：韩公武宅（卒 822）、韦文恪宅（文宗时）、张议潮宅（咸通六年赐第）、邠宁/东川/振武/鄂州进奏院（中晚唐）、奉慈寺（9 世纪前叶）、郭暧宅（安史后）均不入 750 图面。榷盐院设置年无载，盐专卖制度在安史乱后强化，不能因《长安志》列目就当作 750 机构。陈子昂、常无名、贾昌宅仅知在坊；彩缬铺仅见二手转引，原书未核。
- **图面处理**：C2.1 画坊界、四墙、四门、十字街、东市西街、北侧外街、11 个隅内/门旁示意区，以及东西 955.5 米、南北 514.5 米尺寸线。只知在坊、明确异期和待核不能落位者，见 A2 与 `data/unplaced.csv`。
- **主要缺口**：本坊无正式考古发掘简报；坊墙、门址、十字街宽度、县廨院界、净域寺院界、杨国忠宅四至均未落实。杨国忠“坊左”究竟指东侧还是别的方位，仍需追原文和后续研究。

## A0 编纂说明

### A0.1 范围与断限

- **时间参照**：天宝九载（750）。这是比较和绘图的参照点，不是所有材料的事件年代。人物宅第、寺院、官署各有自己的起讫；不能确认 750 年存续者，标 `†` 或列入待核，不当作 750 现状。
- **空间范围**：唐长安外郭城宣阳坊坊域、坊界、墙门、街巷、隅内对象。东市、平康坊、亲仁坊、崇义坊只作相邻关系，不写其内部。
- **对象范围**：坊域与边界设施、街巷水系、佛寺、家庙、官署、宅第、商业、社会史杂记、研究史。
- **不写入**：没有本址依据的院落平面、建筑尺寸、屋顶形制、植被配置；只有名称或仅知在坊的对象不落点；现代地名、展示方案不作为唐坊界。

- **十字街**：连接四门的井字形主街中的十字形部分；本坊街宽无直接记载。

- **榷盐院**：盐专卖管理机构，设置年代与宣阳坊院址均待核。

## A1 坊域

### A1.1 位置与四至

- **坊序**：《长安志》卷八、《唐两京城坊考》卷三列朱雀门街东第三街街东从北：翊善、永昌、来庭、永兴、崇仁、平康、**宣阳**、亲仁、永宁、永崇、昭国、晋昌、通善、通济。宣阳为第七正坊。百度百科作“第六坊”，与两书序列不合，不采用。[XY-S01](#xy-s01)、[XY-S02](#xy-s02)、[XY-S20](#xy-s20)
- **四至**：西界朱雀门街东第三街，即启夏门街；北界平康坊；南界亲仁坊；东界东市西街。东市在宣阳坊之东，占二坊之地，“四面街各广百步”。[XY-S01](#xy-s01)
- **街轴**：第三街“北当大明宫之兴安门，南当启夏门”，是整条街的南北对景，不表示宣阳坊北门正对兴安门、南门正对启夏门。
- **今地一说**：百度百科称坊址在今西安城南和平门外刁家村、李家村与空军四五一医院之间。属现代地名比定，未核考古，只作 C 级线索。[XY-S20](#xy-s20)

### A1.2 坊界与尺寸

- **东西**：吕大临《长安图》称“皇城左右共七十四坊，各四门，广各六百五十步”。宣阳坊属皇城东第一街，东西六百五十步有直接依据。[XY-S03](#xy-s03)
- **南北**：吕图只给“皇城左右”坊的东西广，没有逐坊给宣阳南北深。本汇编参照同街平康坊和皇城以南九坊“南北各三百五十步”，暂按三百五十步作图；这是推导，不是本坊实测。[XY-S03](#xy-s03)、[XY-S02](#xy-s02)
- **折算**：按 1 步≈1.47 米，650×350 步约 **955.5×514.5 米**。唐尺、步折算有小数差，图面取一位小数，不表示测距精度。

### A1.7 地表、植被与庭院

- **寺庭**：《寺塔记》称净域寺“东廊，树石险怪，高僧亦怪”，是寺院庭院有树、石的直接文字，但属文学性记闻，不能定树种、位置、数量。[XY-S08](#xy-s08)

### A1.8 材料与色彩

- **寺**：净域寺佛殿东廊古佛堂“堂中像设悉是石作”，三阶院、万菩萨院有壁画；是石作佛像与壁画，不是建筑通体石材。[XY-S02](#xy-s02)、[XY-S08](#xy-s08)
- **宅**：《明皇杂录》“土木被绨绣，栋宇之盛，两都莫比”是文学夸饰；“皆承以木瓦”是虢国宅中堂屋面做法，能说明用瓦，不足以复原色彩。[XY-S02](#xy-s02)、[XY-S05](#xy-s05)
- **图面**：灰度图不表现材质、色彩；不以文字夸饰推填色。

### A1.9 功能分区

- **东南**：行政。万年县廨在此，县门屋、婚席故事均指向官署建筑。
- **西南**：佛教。净域寺在此，附近有窦毅宅归宁院施寺的关系。
- **东北**：住宅。郭元振宅在此；东门之北另有李济物宅。
- **西侧与十字街附近**：住宅密集。韦巨源、李诲、李乂、高仙芝等宅分列门街。
- **中部偏东**：诸杨宅。与东市、县廨的关系不能确定。
- **东侧**：隔街为东市，商业活动主要在坊外市场，坊内仅见彩缬铺一条待核材料。

## A3 对象间关系

### A3.1 建筑—建筑

- **诸杨宅**：虢国夫人宅在杨国忠宅北（“国忠在其南”）；《新唐书》称“虢国居宣阳坊左”，《旧唐书》称“国忠与虢国……于宣义里构连甲第”，《唐两京城坊考》引毕氏称“国忠第在宫东门之南，与虢国相对，韩国、秦国甍栋相接”。三处尺度不同：坊内、宣义里、华清宫山第，不能混为一条。[XY-S02](#xy-s02)、[XY-S04](#xy-s04)、[XY-S05](#xy-s05)
- **奉慈寺沿革**：虢国宅 → 安禄山伪京兆尹府 → 郭暧宅 → 奉慈寺。是同一地块的历时沿革，不是 750 年同时并存。[XY-S02](#xy-s02)、[XY-S08](#xy-s08)
- **窦毅宅**：宅西有皇后归宁院，后施净域寺；宅南有杞公庙。三者相邻，但院界、庙界未记。[XY-S01](#xy-s01)、[XY-S02](#xy-s02)
- **韦巨源宅群**：韦巨源宅在西门之北；宅东有刘希进、杨务廉宅；次西北隔巷有韦叔夏、单思远宅。只可定相对方向，不能排成一列或画出巷宽。

## B1 宗教建筑

### B1.1 净域寺（XY-B1-01）

- **标识**：XY-B1-01；图面 `XY-ZONE-JINGYU`。
- **直接记载**：《长安志》卷八：“坊西南隅凈域寺。隋文帝开皇五年立。恭帝禅位，止于此寺，薨焉。”《唐两京城坊考》卷三同，并引《酉阳杂俎》：“本太穆皇后宅。寺僧云：三阶院门外，是神尧皇帝射孔雀处。佛殿内西座蕃神甚古质，贞元已前西蕃两度盟，皆载此神立于坛而誓。”《寺塔记》记王昭隐画、火目药叉、北方天王、万菩萨院、皇甫轸画鬼神及雕、佛殿东廊古佛堂“其地本雍村”“堂中像设悉是石作”“相传云隋恭帝终此堂”。[XY-S01](#xy-s01)、[XY-S02](#xy-s02)、[XY-S08](#xy-s08)
- **人物与年代**：隋开皇五年（585）立；恭帝杨侑禅位后居此，武德二年（619）卒；寺本太穆皇后宅为寺僧传说；天宝初独孤明宅与寺相近；大历中仍有舍利、金铜塔事；贞元前西蕃盟誓载寺内蕃神。750 年寺院存续较可能。[XY-S02](#xy-s02)、[XY-S08](#xy-s08)
- **制度背景**：隋文帝立寺、唐初政治人物舍宅为寺；寺院位于坊西南隅，与窦毅宅归宁院施寺的记载互证。净域寺是宣阳坊内唯一有连续沿革记载的佛寺。
- **同类参照**：长安坊内佛寺多由宅舍改造，前身宅主、院额、壁画往往并见；净域寺的“三阶院”“万菩萨院”“古佛堂”是院内院额，不是三座独立寺院。
- **推导**：寺院在西南隅较可能；院界未定，不能把整个西南隅都画成寺。750 年存续较可能，但院额、院数、塔位不能复原。
- **分布**：坊西南隅；窦毅宅在南门之西，宅西归宁院后施净域寺，故寺可能在窦宅西侧，靠近坊西墙或南墙西段；具体四至未记。
- **大小**：无院广、院深、殿宇尺度记载；不能由“西南隅”推占满四分之一坊。
- **材质与植被**：石作佛像、壁画、东廊“树石险怪”；是像设与庭院片段，不是建筑通体石材或完整园林。
- **不能证明**：寺占满西南隅；三阶院、万菩萨院、古佛堂的排列；寺门朝向；塔位；今址。
- **待查**：净域寺遗址；院界；寺额；《寺塔记》与《名画记》画壁的对应；大历舍利塔的下落。

### B1.2 奉慈寺（XY-B1-02，异期）

- **标识**：XY-B1-02；不进入 750 图面，只在 A2、C4 记沿革。
- **直接记载**：《唐两京城坊考》卷三：“奉慈寺。本开元中虢国夫人杨氏宅。虢国即贵妃之姊。其地本中书令马周宅。”《寺塔记》：“安禄山伪命百官，以田乾真为京兆尹，取虢国宅为府。后为驸马都尉郭暧宅。今上即位之初，太皇太后为升平公主追福，奏置奉慈寺，赐钱二十万，绣帧三车，抽左街十寺僧四十人居之。”《唐两京城坊考》引《寺塔记》作“赐钱二千万”，与《酉阳杂俎》异文，待核。[XY-S02](#xy-s02)、[XY-S08](#xy-s08)
- **人物与年代**：开元中为虢国夫人宅；天宝末安禄山据长安，取为京兆尹府；安史乱后为郭暧宅；9 世纪前叶，太皇太后郭氏为升平公主追福，立奉慈寺。具体立寺年待核。
- **制度背景**：舍宅为寺、公主追福立寺；奉慈寺与虢国宅、郭暧宅同址，是同一地块的历时沿革。
- **同类参照**：长安公主、外戚宅舍为寺者多见；奉慈寺的“赐钱（二十万/二千万异文）、绣帧三车、抽十寺僧四十人”是立寺规模，不是寺院面积。
- **推导**：寺在虢国宅旧址，即诸杨宅地块；不能把奉慈寺画在 750 年图面，也不能把“寺”与“虢国宅”并列成两座建筑。
- **分布**：与虢国宅同址，具体四至随诸杨宅待核。
- **大小**：无寺院面积、殿宇数。
- **材质与植被**：无直接记载。
- **不能证明**：奉慈寺在 750 年已存在；寺额沿用到唐末；寺址即今七十一中学。
- **待查**：立寺确切年；寺址；与郭暧宅的改建关系。

- **大小**：无庙广、庙门、殿庑记载。
- **材质与植被**：无直接记载。
- **不能证明**：庙在 750 年仍存；庙的朝向、门位、院数。

## B2 宅第

### B2.1 杨国忠宅与虢国夫人宅（XY-B2-01/02）

- **标识**：XY-B2-01 杨国忠宅；XY-B2-02 虢国夫人宅。图面 `XY-ZONE-YANG`，只画相对位置示意区。
- **直接记载**：《新唐书》卷206：“虢国居宣阳坊左，国忠在其南，自台禁还，趣虢国第，郎官、御史白事者皆随以至。居同第，出骈骑。”《唐两京城坊考》卷三：“前司空、兼右相杨国忠宅。虢国夫人居坊之左，国忠第在其南。”又引毕氏：“《唐书》云，国忠第在宫东门之南，与虢国相对。韩国、秦国甍栋相接。”《旧唐书》卷106：“贵妃姊虢国夫人，国忠与之私，于宣义里构连甲第……国忠山第在宫东门之南，与虢国相对。”[XY-S02](#xy-s02)、[XY-S04](#xy-s04)、[XY-S05](#xy-s05)
- **人物与年代**：杨国忠，天宝十一载（752）拜右相；750 年已为玄宗宠臣，宅第见载。虢国夫人为贵妃姊，开元中已有宅；天宝末势倾一时。安禄山入长安，取虢国宅为京兆尹府；王维、郑虔、张通等被囚于宣阳里杨国忠旧第。[XY-S02](#xy-s02)、[XY-S05](#xy-s05)
- **制度背景**：外戚甲第、坊内宅第逾制；诸杨宅“甍栋相接”是当时权贵宅第聚集的例证。杨国忠宅的“前司空、兼右相”是后修史时的追叙，不是 750 年官衔。
- **同类参照**：平康坊李林甫宅、亲仁坊安禄山宅、崇仁坊长宁公主宅等，都是坊内权贵甲第；可作规模参照，但不能把它们的院数、面积直接套到宣阳坊。
