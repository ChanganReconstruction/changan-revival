# 浮图院 · 单体复原卡

[总平面与坐标](README.md#总平面) · [来源索引](sources.md) · [JF-01 荐福寺塔](pagoda.md)

尺寸单位米。木构平面默认给**最外柱轴**，出檐从外柱轴向外水平量；墙坐标按外皮。下列建筑形制数值均为本版采用值，不是本址考古测绘。

## JF-02 北门

**依据与采用。** [JF-S12](sources.md#jf-s12)、[JF-S01](sources.md#jf-s01)支持北开，与寺本部门隔街相对，不定门屋形制。已发掘的北坊墙角门未证为此门，且未见墩台，宽度不详 [JF-S13](sources.md#jf-s13)。用[寺观手册](../handbook/temples.md)的门—院组织作类型参考；采用单层三间门屋，不加二重门或楼阁。门屋中轴对塔是布置选择。

| 部位 | 本版采用 |
| --- | --- |
| 柱网 | 面阔 `11.40`：西至东 `3.40 / 4.60 / 3.40`；进深 `5.40`，两排外柱；柱径 `0.40`。两边间作封闭或半封闭墙身，本版用封闭土色抹面、南侧无侧门。 |
| 台明与门口 | 台明边界 `X=-6.10–6.10, Y=36.20–42.40`，台面 `Z=0.30`。明间门洞净宽 `3.60`、净高 `3.10`（从门槛顶量），门扇在中间进深 `Y=39.30`；门槛顶 `Z=0.38`。台明两面各二级步，踏步宽 `4.20`、水平进深 `0.60`。 |
| 立面 | 单檐两坡、山面在东西，脊沿东西。檐口 `Z=4.35`、脊顶 `Z=6.10`；南北出檐 `0.95`，东西出挑 `0.55`。用低对比筒板瓦，简化脊端，不采用现景区匾额与吻饰。 |
| 节点 | 飞檐弧度从简，不用清式高翘。墙接北排两端柱轴；门扇、门槛与台明分件。进门后可沿 `X=0` 到北踏步，步道也可从两侧绕台基。 |

## JF-03 院墙

本版采用高 `2.35`（含压顶）、厚 `0.55` 的土色抹面墙身；下部 `0.25` 高做耐磨墙脚，顶部低矮瓦压顶向两侧出 `0.10`。围合和压顶做法均是类比与灰模暂定，不能用来判断唐代院墙构造。北段与门屋相接；南、东、西墙不另开历史未定的门。墙角实接，墙脚不画连续石砌高台。

## JF-04 院面与步道

院地通用压实土，色差区分北门到塔前的引道与周边院地，不铺现代方砖广场。塔台周围沿四边留 `0.60` 宽的细碎料散水带，踏步经过处断开，不设抬高路缘；不占用两侧绕塔空间。南侧空地与东房门前接平院地。材质、铺法与平院假设皆为项目采用值；第一版不加水池、石栏、井或指定历史树种。

## JF-05 东侧附屋（无名）

**没有本址单体证据。** 为给塔院一个低矮的侧向体量，借[附属堂屋类型](../handbook/temples.md)缩窄为一座三间房，不定为僧房、经堂或食堂，不挂牌，不与现代殿宇配对。

| 部位 | 本版采用 |
| --- | --- |
| 柱网与方向 | 面西；沿 `Y` 面阔 `10.00`（南至北 `3.20 / 3.60 / 3.20`），沿 `X` 进深 `5.00`；柱径 `0.28`。 |
| 台明与门窗 | 台明外伸 `0.30`、台面 `Z=0.24`；西面明间门洞净 `1.50×2.15`，中心 `(24,-15)`；门前两级踏步宽 `1.90`、进深 `0.50`。西立面两个次间各用一扇 `0.85×0.95` 木格窗，窗台离台面 `0.90`；东、南、北面不另开口。 |
| 屋顶与材料 | 单檐两坡、南北向脊，檐口 `Z=3.10`、脊顶 `Z=4.60`；东西出檐 `0.70`，南北出挑 `0.40`。灰瓦、土色抹面、素木门窗；无重檐或高台。 |
| 使用范围 | 做外观与门口，不规定家具或内部功能。可整栋移除，不影响北门—塔的空间关系。 |

## JF-06 塔副阶（可切换）

**依据与采用。** 柳宗元《鶻说》记塔下“室宇” [JF-S16](sources.md#jf-s16)，未载平面。据 [JF-S07](sources.md#jf-s07) 转引，北宋政和六年（1116）《大荐福寺重修塔记》记塔外“周徊副屋”受损后“悉皆修完”；待核碑录拓片 [JF-S15](sources.md#jf-s15)。[JF-S11](sources.md#jf-s11) 无名续注记 1215 年“塔之缠腰”尚存，又记辛卯迁徙后“廢蕩殆盡，惟磚塔在焉”。不能据此认定为同一构造、确定具体毁期或断言 750 年已存在。台基与塔身的现代尺寸只表明展示方案有布置空间，不能证明旧柱脚。此层默认关闭；启用时标“1116 年碑文转引；形制为展示假设”。

| 部位 | 本版采用 |
| --- | --- |
| 柱网 | 绕塔一周五间，外柱轴 `X/Y=±8.10`；每面 `16.20`，分五间各 `3.24`，共 `20` 柱（四角共用）；柱径 `0.35`，柱础 `0.70×0.70×0.12` 方础，全部灰模。 |
| 台基与地面 | 直接立在塔台面上，`Z=3.20`，不另起台明；檐下地面铺 `0.30` 厚素砖一圈，外缘与塔台散水相接。若台面改取 `3.5` 说，副阶整体随台面平移。 |
| 立面 | 倚塔单坡腰檐：外檐口 `Z=7.50`，靠塔一侧升至约 `Z=8.30`；外挑 `0.55`。柱头用单栱素枋，补间一朵人字栱，不设普拍枋、不施彩画；形制参照盛唐五间殿堂及大雁塔一层西门楣线刻。 |
| 屋顶与交接 | 筒板瓦、无正脊（单坡），檐口用素瓦当；与塔身交接做 `0.25` 高泛水，不把瓦面插进砖缝。 |
| 开关方式 | 整组一个图层：柱、础、额枋、屋面、铺地同时显隐；关闭后塔台面保持干净，不留柱洞。不得只保留屋面而删柱。 |

## JF-07 西侧配屋（无名，可移除）

**没有本址单体证据。** 只为检验“院墙内如果两侧都有附属体量”的观感，把 JF-05 镜像到西侧：柱轴 `X=-29–-24, Y=-20–-10`，面东，入口中线 `Y=-15`；面阔、进深、台明、门窗、屋顶均与 JF-05 相同，仅方向相反。默认关闭，可整栋移除。不得据此推断唐代塔院一定对称，也不给它安僧房、库房等具体名称。
