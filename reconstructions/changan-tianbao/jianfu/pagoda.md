## 十五级塔身与密檐：展示方案

[逐级 CSV](pagoda-levels.csv) 是展示参数表，单位米。`Z=0` 为本版院面，`body_base_z` 为该级起点，`eave_top_z` 为该级檐部上口，也是下一级的起点。两个 `body_side` 尺寸均指**砖身外皮的方形边长**（不含檐）：每级内作线性收分，逐级改变收分率。第 1 级底边和台高借用现代尺寸转述；其余分级数值不作为测量结果。第 6 级起加大收分是展示轮廓选择，不是实测到的折点。

1. **逐级放样。** 每级按方形出檐，不按圆形处理；`eave_projection` 是相对于该级 `body_side_top` 的单边最大水平挑出，最大檐宽 = `body_side_top + 2 × eave_projection`。局部砖身维持收分，不加木构仿形或瓦垄。
2. **檐口剖面。** `eave_band_height` 自 `eave_top_z` 向下量。设檐带底至顶的归一化节点 `(高度比例, 挑出比例)` 为 `(0,0) → (0.28,0.26) → (0.53,0.53) → (0.76,0.80) → (0.90,1.00) → (0.96,1.00) → (1.00,0)`。起点接檐带底处的收分墙皮，其余节点的水平坐标以 `body_side_top / 2` 为基线加上相应挑出量；相邻节点间按砖叠涩出挑，上部短斜面收回砖身。檐带最下两道表现为菱角牙子；近景按可辨砖层调整，不把此节点图当成原塔精测砖皮。砖缝可先用实体与贴图混合表达；本版面砖模数暂用 `0.32×0.08`（长×皮高，含缝），非唐砖规格认定。
3. **券口与窗台。** 第2–13级南北面中线设置半圆拱顶券窗。表内 `opening_sill_z` 是洞口下沿，`opening_height` 是净总高，起券高为洞口下沿＋净总高−净宽的一半。券窗可做 `0.65` 深的暗凹以表现外观，不据此定真实贯入深度。窗左右各做低短砖叠涩台，本版每段宽 `0.60`、高 `0.16`、出挑 `0.16`，靠券口留 `0.15` 缝；东西面不加对应假窗。第14、15级位置失传，本版沿用南北小券窗作为延续推定。
4. **区分现状参照与缺失段。** 方案在 `Z=43.60` 接续第 14、15 级及塔顶；接续点不是实物测点。缺失段的层高、边长与券窗仅为展示补全，不复刻现状残顶或封顶。

## 塔顶与塔刹：展示备选

十五级檐顶取 `Z=46.50`。本版用方形浅斜砖顶，从该处边长 `4.00` 收至 `Z=47.40` 的中央 `1.60` 米见方小平台；平台以上用素面刹座、逐级缩小的相轮和收尖轮廓。不采用现状平截顶作为唐代塔顶。

| 标高（米） | 本版采用几何 |
| --- | --- |
| `47.40–47.90` | 方座边长从 `1.60` 收至 `1.28`。 |
| `47.90–48.50` | 圆形刹身最大径 `1.03`，向上收至 `0.52`。 |
| `48.50–49.80` | 以直径 `0.25` 刹杆串五道简素圆轮；中心标高取 `48.62 / 48.86 / 49.10 / 49.34 / 49.58`，径 `0.90 / 0.82 / 0.74 / 0.66 / 0.58`；每轮厚 `0.11`。 |
| `49.80–50.55` | 上端过渡为最大径 `0.54` 的小型收尖宝珠，尖顶 `Z=50.55`。 |

**整段属可替换的展示几何。** `50.55` 米是在方案檐顶 `46.50` 米上叠加的结果，两者均不是照片量值。无须给刹座指定历史材质；方案用较暗的素色，与暖灰砖身分开。第 14–15 级、斜顶和刹保留为可分别撤换的部分。

## 副阶（JF-06，可切换）

柳宗元记塔下“室宇” [JF-S16](sources.md#jf-s16)；北宋“周徊副屋”见 1116 年碑文转引 [JF-S07](sources.md#jf-s07)，可追查碑录 [JF-S15](sources.md#jf-s15)；金代“塔之缠腰”见《游城南记》无名续注 [JF-S11](sources.md#jf-s11)。目前不能把三种称谓等同，更不能据此确定 750 年形制。按现代尺寸转述，同心台基每侧净余约 `(23.38−11.38)÷2=6.00` 米，只用于检验绕塔方案是否放得下，不能证明历史柱位。副阶默认关闭；开启时标“1116 年碑文转引；形制为展示假设”，不得写成 750 年实证。几何与类比见[单体卡 JF-06](buildings.md#jf-06-塔副阶可切换)。

## 近景取材与年代排除

砖面明暗以砌体、叠涩投影及券洞深度为主；踏步用中性灰石，台面用低对比素砖，不套现代广场铺装。现状照片看构造与光影，不照抄当前斑驳分布。排除明代题刻、震裂残顶、修缮铁箍、避雷针与现代楼梯；不从现状受损推断750年的原色或砖缝填料。[JF-S02](sources.md#jf-s02)、[JF-S03](sources.md#jf-s03)
