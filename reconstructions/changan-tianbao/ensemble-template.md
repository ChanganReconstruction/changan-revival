# 建筑群复原模板

[天宝长安项目入口](README.md) · [建筑群复原工作准则](ensemble-workflow.md) · [里坊资料汇编模板](ward-template.md) · [通用史料手册](handbook/README.md)

**只要求一份主文档（通常是 `README.md`），其余按需附。** 里坊级回答对象在坊内哪里、与街巷和周边有什么关系；重点建筑群级细化到院落、单体和构件，回答哪些形制有据、能复原到哪一步、每个关键取值为什么这样选。精细指可以逐项核对，不是一定要画全或给出尺寸。

## 一、用途与设计原则

沿用里坊模板的「核心—按需模块—附录」组织方式，但不照搬坊域对象分类。坊级主图把院落作为整体；专项从院落内部开始，细化到单体和构件。引用已有坊级条目，不重抄坊域材料；低精度的坊级位置也不能直接变成总图坐标。

固定的是主文档的入口和审查口径，不是文件数量或篇幅。影响判断的缺项须说明，非关键空项可合并或省略。不为凑齐章节补建筑、凑图纸或拟定数字。

## 二、目录结构

以下是**一份主文档的章节目录，不是文件树**。

```text
A 核心（必设）
  A0 编纂说明：目标时点、复原与展示范围、上游版本
  A1 沿革与分期：营建、改修、毁损、现状测绘
  A2 对象总表与建筑群布局：院界、出入口、院落与单体关系、地坪
  A3 重点单体详条：平、立、剖、构造、材料与证据边界
  A4 复原方案与取值：历史约束、推定、展示占位、备选与待查

B 模块（按问题启用）
  B1 重复构件：逐级、逐间或分面记录
  B2 基础与内部：台基以下、内部空间及不能确认的范围
  B3 关键节点：构造、装饰与材料分期
  B4 竞争方案：影响布局、轮廓或断代的不同解释

C 附录（保留入口，内容按需）
  C1 来源总目：也可就地引用，无须重复抄录
  C2 图版与附件：可以复用、内嵌或说明不成图
  C3 修订记录：注明改了什么依据，以及影响哪些结论或图表
```

### 核心字段

| 章节 | 最少要交代什么 |
| --- | --- |
| A0 编纂说明 | 目标时点与选定理由；历史范围、实际复原范围和展示裁切范围；坊级定位的上游出处和固定版本。 |
| A1 沿革与分期 | 关键的营建、改修、毁损和测绘阶段，逐项注明涉及对象或部位。无法断代的部分不从现状倒推。 |
| A2 对象与布局 | 对象名称或编号、归属院落、目标期存在状态和定位精度；分开说明坊街衔接、出入口、院界、轴线、建筑之间的关系、地坪及高差。使用坐标时注明原点、方向、单位、高程基准和配准状态。坊墙、院墙和场景边框分别处理。 |
| A3 重点单体 | 每个核心单体给一张卡或一节，写分期、平面、立面、剖面、构造和材料。附属对象可简写，但是否存在、是否入方案及依据须明确。 |
| A4 复原方案与取值 | 逐项列出影响位置、轮廓、开口、构造或断代辨识的取值依据、量取基准和采用理由。仅交考证就明确写不做展示；有缺口则交代查过什么、缺什么、影响哪项判断。 |

文献对象与实掘遗迹可能对应、但尚未证实时，在 A2 分开记录两者，说明对应理由、缺少的证据，以及各自是否进入目标期总图。不为此另设必填表或附件。

## 三、模块启用表

下面是启用条件，不要求每个专项重复抄表。启用的内容可就地写在对应详条、总图说明或 A4；不另开文件或重复记录。没有材料但会影响判断的，在 A4 交代缺口。

| 模块 | 何时展开 | 写什么 |
| --- | --- | --- |
| B1 重复构件 | 塔的级、殿堂的间或建筑的各面不能用一组数据概括 | 标明级、间或朝向，分别记录边线、标高、开口及其出处；分开现存与缺失部分。 |
| B2 基础与内部 | 材料涉及基础、地宫、内部交通或层间结构，且影响断代或几何 | 写清层位、测点、能追到的内部边界；不能确认处止于已知范围。 |
| B3 关键节点 | 某项做法会影响定年、轮廓或近景辨识 | 对照遗存、后补和类比，注明可用于复原的部位与限制。 |
| B4 竞争方案 | 不同解释会改变院界、轴线、外轮廓或关键尺寸 | 并列各说、依据、采用理由及影响；不能判定时保留备选或未定。 |

## 四、详条字段

| 栏目 | 审查要点 |
| --- | --- |
| 分期 | 目标期的存在和功能是否有据；哪些部分尚存、后补、重建或缺失。只知某部位后世见载，就不写成目标期已有。 |
| 平面 | 位置、朝向、外轮廓、开间与进深（如适用）、承重体、出入口与通行。注明量的是墙外皮、柱轴还是檐口。 |
| 立面 | 台基与踏步、层或级、各面开口、屋盖或檐线、最高点；四面资料不同就分别说明，不以一个立面复制其余三面。塔等重复构件按级记录能辨别的差异，不从存段自动补足失段。 |
| 剖面与构造 | 地坪到台面、主要竖向基准、承重与围护、屋盖或砖檐等关键节点；剖面到哪里有依据、哪里只能示意。内部无据可不做，不必为了闭合剖面虚构楼板或墙厚。 |
| 材料与年代特征 | 可辨认的材料、砌筑或木作、瓦作、铺地和色彩；分清本址遗存、后世替换、同类参照及展示材质。只写影响断代或表现的要点。 |
| 方案边界 | 写明哪些参数属于制作方案、哪些部分不做或可替换。若不同解释会改变总图或外轮廓，并列说明影响，不用混合值掩盖分歧。 |

例如**塔**重点核对级数、逐级檐口、收分、分面券口、残顶与刹；**木构门殿**重点核对柱网、开间进深、台明、屋盖及关键铺作。不是每类建筑都套用同一组构件。

## 五、证据与取值的标注

引用核查、推导强度、方位精度与空值沿用[里坊模板第六节](ward-template.md#六证据与推导的标注)；不另立一套等级。引用上游坊级甲乙丙丁时，保留其对应主张，不把某项方位的等级移给院界、构造或尺寸。下表补充的是这些材料**如何进入本期建筑复原**，并非另一套证据等级。

一行只判断一个属性，例如门朝向、门的具体位置、是否与塔同轴应分别记录。重要属性用以下状态；同一个对象的不同属性可以是不同状态：

| 状态 | 写法 |
| --- | --- |
| 目标期本址支持 | 引到具体原文、图版或遗存，写明它能证明到哪一步。 |
| 后世或现状参照 | 标材料对应阶段；如借入目标期方案，说明为何可借以及哪些部分不可借。 |
| 有前提的推定 | 写明从哪条线索推出；借用同类实例时说明年代、地区、功能或形制的可比性，以及不能照搬之处。 |
| 未定 | 按实际注明「原文未载」「已查未见」「尚未查核」或并列异说；不适用单列。留白不等于不存在。 |
| 展示占位 | 不是证据状态。只在方案栏记录采用理由、是否启用和可否撤换。 |

**出处**写到卷页、条目、图号或遗迹号，按通用规则标「直接」「转引（已核）」「转引（未核）」或「待核」。分别写材料成文或测量时间与它描述的阶段；古籍的后世汇辑和今天的新闻转述，都不能不加说明地写成同期记录。

**尺寸**写单位、测点、起止与基准，区分实测、测量转引、图像估算、推导或占位；同一参数在不同方案中的采用值注明归属。有推导就列输入和计算方法。图像估算须能从图像、标点、比例来源和透视处理复核；不能复核时，只作定性参照或把数值降为展示值。没有依据不写公差，不用现代残高补算已失构件的原高。

## 七、编号、图版与附件

- **编号**：对象沿用既有专项编号；引用坊级条目时保留坊级编号，不重编。单体详条、图题与取值表使用同一对象编号；图表多时再单独编号。

- **来源多或反复引用**：可单列 `sources.md`；少量出处就地引用或放文末。
- **一张图能说明关系或构造**：A2 的总图入口可引用既有图版；只知相对关系时用不按比例的关系图，不能判定布局就用对象表或注明不成图。单体平立剖及节点图按依据和需要配，不要求套图。
- **正式总平面**：交 GeoJSON 和同源布局图；无法落位时保留占位，不造坐标。源数据、渲染清单和本地预览按[工作准则](ensemble-workflow.md#五总平面geojson-与本地预览)办理。
- **图面表达**：图题标对象、阶段和用途，并注明出处及量取限制。按证据精度表达位置和边界，未知不闭合；有方向依据才标北向，有可靠尺度且按比例绘制才标历史图比例尺。米制展示图可标方案比例尺，但只能量得方案尺寸。用线型、图例或文字区分有据、推定和展示占位。
- **大量重复参数或下游需要读取**：再放 CSV，例如塔的逐级尺寸。同一个参数保留一个取值来源，正文和图引用它；表格被单独拿走时仍应看得出哪些是展示值。
- **确有独立资产交接**：再附资产清单，注明所用文档或数据版本及可替换部位。既有专项不必为套模板搬文件。

## 八、适配与验收

主文档保留 A 段核心入口和 C 段附录入口，B 段随材料增减。允许合并表格、复用图版或把长表另附，只要正文能直接找到对应依据。不要求同类专项篇幅、图数或编号数量相同。

- **史料审校**：目标期存在与具体形制分别有依据；定位精度不超过出处；关键断言能追到具体出处和核验状态。把一个核心单体的平、立、剖逐项读一遍，应能区分已知、推定和未知。
- **制作交付（如有）**：选取一条关键尺寸，从图或模型说明追到采用值、量取基准、来源或制作理由；正文、数据与图的编号、方向、阶段和启用状态一致。展示占位可辨、可撤换，图表脱离正文也不被误读为历史测绘。

示例：[小雁塔塔高与逐级尺寸](jianfu/pagoda.md#塔高与逐级尺寸审校)在原单体文档内试填，不另立证据表或参数文件。
