# 里坊资料汇编目录模板

[天宝长安项目入口](README.md) · [通用史料手册](handbook/README.md) · [坊市资料构建工作准则](ward-workflow.md)

本文件是坊市资料汇编的共用骨架与标注规范，不规定内容上限。具体条目、出处和结论写在各自的坊市文件中。

## 一、用途与范围

- 适用于唐长安里坊与市场的资料整理与复原说明。
- 统一章节、字段、分级、编号和空值写法，便于横向比较。
- 不规定建模参数，也不替任何一坊补默认尺寸。
- 有明确依据、与本坊市或其复原有关的信息，尽量收录。不因缺少对应栏目而舍弃材料，也不为填满栏目而推测。
- A 核心、B 专题、C 附录作为共用骨架；下级栏目可按材料合并、拆分或增补。较长的材料可另作附表或专题页，由主文链接。

## 二、设计原则

1. **同构可比**：顶层结构与共用字段含义一致；不要求下级目录或篇幅完全相同。
2. **按材料展开**：核心保留，专题按材料启用；已有依据的信息尽量写全。
3. **证据优先**：资料可追到出处；按具体主张说明能证明什么。只有推导才标推导强度。
4. **缺项如实**：区分原文未载、已查未见、尚未查核和不适用，不把缺材料写成不存在。
5. **编号可引**：坊码 + 模块 + 序号，支持跨坊引用。
6. **标准共用**：分级、字段、术语、引用格式只在本文件定义一次。

## 三、目录结构

```text

    A0.2 材料类型与来源层级

    A0.6 方位精度：坐标 / 隅 / 门街 / 相邻 / 仅坊 / 无
    A0.7 详条字段模板（十项）
    A0.8 缺项与查核状态
```

正文或对象总表已能快速检索的内容，不必另抄一遍做索引。统计须注明所计时期、单位和纳入范围，分清材料条数、对象数和本期可确认的对象数；口径未定可不统计。

### C2 平面图要求

本模板只规定两类平面图，不规定图的总张数。一个复原目录对应一个时期，不另设分期图；异期材料可在同图中另标为旁证，不作为本期现状。C2 登记图名、所示时期、出处、主要未知项和图版状态；院落内部图另记对象编号。可复用已有合适的图版，不重复制图。

先系统检索和整理证据，再集中制图；可用未逐条写入正文、但能回查出处的空间信息。新制图登记 GeoJSON 源文件和渲染清单，用绘图器生成本地 PNG 审阅，不要求 SVG。入图判定、绘图步骤和验收见[工作准则：GeoJSON 平面图与本地预览](ward-workflow.md#五geojson-平面图与本地预览)。

#### C2.1 坊市平面分布图（必设）

回答「本坊市在城内哪里，内部对象如何分布」。A1 坊域和 A2 对象总表引用同一主图。

- **骨架与对象合绘。** 画出有据的坊界或市界、门、街巷、水系和对象分布，不只排地名。复原示意可用直街接门等简单、可通行的方案，明确标为示意；考古实证部分只画有依据的墙段、门道等，不为闭合或连通补画遗迹。院落在主图上作为一个整体，以对象编号标识，内部关系需要展开时另见 C2.2。
- **交代周边区位。** 在图边标注有助于定位的相邻坊市、主要道路或城门，或引用已有全城图；不要求另制周边区位图。
- **按已知方位落图。** 仅知某隅、某门一侧或相邻关系，把符号或占位块放在对应位置，注明更细位置未定；不当作精确点位或地块边界。仅知在坊市内的对象列入图旁的未定位清单。
- **区分本期、待核和旁证。** 方位有据但本期存续待核、明确异期或属于出土记录的，可按已知方位上图，用图例和就地标注与本期现状区分；出土方位不等于原使用地点。相互竞争且有据的落位注明为备选，不当作定论。
- **关键尺寸和限制直接入图。** 有依据的总体长宽用尺寸线和两端界线表达；墙基长宽、角门距角等局部尺寸标在对应构件旁。总图可辨四隅时标四隅；边界是否闭合、哪些门已确认等关键限制就图说明，区分「目前只确认两门」与「确认只有两门」。
- **允许缺图。** 能说明相对关系但不能定比例时，可用不按比例的示意；不足以成图时，保留图位并注明缺项，不以假设填满。

#### C2.2 院落内部图（按需，逐院成图）

回答「院内有哪些建筑，彼此怎样组织」。仅在有依据表达内部空间关系时启用，不要求每个院落配图。

- **有关系才成图。** 表达门、堂殿、廊庑、附属建筑等已知的前后、内外、相邻或出入关系。只知道有哪些建筑、不知道相互位置时，列清单，不画平面。
- **有尺度才按比例绘制。** 只有相对关系时，画不按比例的关系图。不补齐未知院墙、轴线、进数、尺寸或通行路线。
- **独立成图，以编号互引。** 图题沿用 A2 对象编号，在对象详条引用；主图能落位的，从主图标号指向院落图。院落在坊市内的位置未知，不妨碍绘制已有依据的内部关系。

两类图均须区分有据内容与复原假设。仅在图面方向有依据时标指北针；仅在有可靠尺度且按比例绘制时标比例尺。不另设骨架图或通用局部图；只有合绘后仍读不清的关系，才考虑在相应图内加插图。

## 四、模块启用表

每坊市在正文前放一张表，说明各模块的启用情况。模块可以因有活动、制度、环境或空间关系等材料而启用，不要求先有一个可编号的建筑。未启用时简述原因，按 6.5 区分已查未见、尚未查核与不适用，不默认写“本坊无”。

| 模块 | 启用条件 | 不启用时 |
| --- | --- | --- |
| B1 宗教建筑 | 有寺、观、祠、塔、院 | 按实际情况注明原因 |
| B2 宅第 | 有宅第、赐第、旧宅、寄居记载 | 同上 |
| B3 官署与机构 | 有官署、进奏院、市署、驿 | 同上 |
| B4 市场与商业 | 有市、店、作坊、行业 | 同上 |
| B5 园林与池苑 | 有园、池、亭、庭院植被 | 同上 |
| B6 军事与空地 | 有球场、营、仓场、废宅 | 同上 |
| B7 生活与风俗 | 有人群、活动、文学材料 | 同上 |
| B8 专题研究 | 有跨对象争议或复原问题 | 可省略，并在 A4 说明 |

## 五、详条字段

以下十项是编写详条时逐项考虑的提示，有信息就写，可按对象增补旧名、用途变化、修造经过等字段。详条至少让读者查到对象名称与编号、出处、材料能证明什么，以及能否用于本期复原。影响判断的缺口须明确说明；其余空项可合并说明或省略，不逐格填空。

对象类别、人物身份和官职等基础事实，也在详条首次出现时注明出处；同一出处支持多项可合引，不必在索引与总表重复。身份或类别的依据不能替代对人物与本址关系、年代或布局的查证。

| 序号 | 字段 | 写什么 | 没有依据时 |
| --- | --- | --- | --- |
| 1 | 标识 | 名称、别名、类型、编号 | — |
| 2 | 直接记载 | 原文短引、出处、年代、关系类型、方位精度 | 说明直接材料的缺口；若有转引或待核线索，另行标明 |
| 3 | 人物与年代 | 人物身份、材料成文年代、所述事件年代、本期是否可见 | 存续或年代不明时注明，不据成文年代补事件年代 |
| 4 | 制度背景 | 营缮令、品级、宅第制度；注明年代差 | 可省略，不拿通用规定代替本址实况 |
| 5 | 同类参照 | 同城、同时、同等级、同功能；逐条写可借与不可借 | 可省略；查过才写“已查未见” |
| 6 | 推导 | 分条结论，每条标强度 | 没有推导就省略，不补数字 |
| 7 | 分布 | 院界、院数、轴线、相邻关系 | 注明影响定位的未知项，其余可合并说明 |
| 8 | 大小 | 院宽深、开间、进深、柱高、台基、墙、屋顶 | 没有尺度依据时注明，不逐项写“本址无” |
| 9 | 材质与植被 | 墙材、瓦色、铺地、庭院花木 | 可合并说明或省略 |
| 10 | 不能证明与待查 | 写明关键证据边界和有用的查证线索 | 按实际缺口写，不套用固定结论 |

## 六、证据与推导的标注

### 6.1 证据分级

按**具体主张**分级，不按来源或对象整体分级。同一材料可为不同主张提供不同程度的支持；引用核对状态另按 6.3 标注，未核转引不写作已证实结论。

| 级 | 可以支持 | 不自动推出 |
| --- | --- | --- |
| 甲 | 本址材料明确记载或实测的具体事项，如对象存在、门街关系、用途、构造、院界或尺寸 | 材料未记或未测的属性、其他地点或时期的情况 |
| 乙 | 某人与坊市的居住、卒地等关联，或仅有部分依据的对象关系 | 具体宅第、产权、精确位置或未被支持的关系 |
| 丙 | 只提到坊市名、坊市内地名，或只能留作旁证的线索 | 本期对象、居住、产权、位置或布局 |
| 丁 | 对所讨论的主张无有效关联或不可用 | 任何该主张下的正面结论 |

- 孤证不自动降级；在出处可核的前提下，按它实际能证明的内容标注。
- 矛盾记载并列，注明出处、所述时期及尚不能判定之处，不合成一条结论。
- 弱线索或异期旁证可写在相关详条、A4 或附录，但不作为本期已证实的对象或关系进入主表与主图。排除的材料只有在有助于解释争议或防止误用时才保留，并注明理由。

### 6.2 推导强度

强度只用于从材料推导出的结论；直接记载或本址实测本身不填推导强度。同类参照和展示假设不写成本址事实。

| 强度 | 含义 |
| --- | --- |
| 较可能 | 有直接前提，且有同城或同类参照支持 |
| 备一说 | 有前提，但存在竞争解释，不能定为一说 |
| 仅可排除 | 只能否定某说法，不能正面推定 |

- 身份只能推出“等级区间”，推不出具体尺寸。
- 制度只作上限，不作实际。
- 同类参照给入口，不直接抄数字；不跨级、不链式。
- 缺少参照时按实际查核状态注明，不拿相似建筑顶替。

### 6.3 引用与转引

| 标记 | 含义 |
| --- | --- |
| 直接 | 引自原文、发掘报告或图版 |
| 转引（已核） | 二手材料给出引用，且已核对原书或原报告 |
| 转引（未核） | 二手材料给出引用，尚未核对原件 |
| 待核 | 只有转述，找不到引用或暂时无法核对 |

- 二手材料只要给出引用，可以照录，但必须保留其引用链。
- 不引百科或自媒体本身，只引它指向的原始材料；找不到原始材料时标“待核”。
- 引用格式统一到卷次、条目、页码、图版号或遗迹编号。

### 6.4 方位精度

| 精度 | 含义 |
| --- | --- |
| 坐标 | 有测绘或考古坐标 |
| 隅 | 只知在某隅 |
| 门街 | 某门之东/西/南/北，某街之北/南 |
| 相邻 | 某宅次北、某寺之东等相对关系 |
| 仅坊 | 只知在坊内 |
| 无 | 方位未记 |

只记录到依据所支持的精度，不补足。图上留白是正式表达。

### 6.5 空值

| 写法 | 含义 |
| --- | --- |
| 原文未载 | 已查看的这一来源没有记载该项；不代表其他来源也没有 |
| 已查未见 | 在已查材料范围内未找到；关键缺口注明查找范围 |
| 尚未查核 | 该项或相关来源尚未核对，不能写成已查未见 |
| 不适用 | 该字段不适用于该对象或事项 |
| 本坊无／本市无 | 有依据说明该事项在相应时间和范围内确实不存在 |
| 已排除 | 有材料，但经核对不能用于所讨论的结论；注明理由 |

## 七、编号

- 坊码用 2–4 个字母，例如 `PK`、`AR`、`CR`。
- 模块号固定为 `B1`–`B8`；新增模块从 `B9` 起，不插号、不重排。
- 对象编号：`{坊码}-{模块}-{序号}`，例如 `PK-B2-01`。
- 跨坊引用只写对象编号，不写页码。
- 条目内字段用固定名称，便于并表和检索。

## 八、适配规则

1. **保留共同骨架**：A 段保留核心入口，B 段按材料启用，C 段保留引用、图版等附录入口；细目可合并、拆分或增补。
2. **材料优先归档**：现有模块可以容纳的，增补小节、字段、附表或专题页；只有需要独立对象类别时才新增 B 模块。
3. **不强行对称**：缺项按 6.5 处理，非关键空项可省略；不拿类比填满。
4. **不重复定义**：分级、字段、术语只在本文件定义，各坊直接引用。
5. **不横比强求**：各坊市材料密度不同，索引、统计及附图按实际需要增设，不要求篇幅对齐。
6. **新增模块**：放在 B 段末尾，并在修订记录中说明。

## 九、跨坊共用层（可选）

若需要跨坊比较，可另建以下共用件，不放进各坊正文：

- `ward-comparison.csv`：只抽关键字段，如坊面积、门数、街巷、寺观数、宅第数、机构、市场、证据等级分布。
- `ward-index.md`：各坊文件、编号前缀与主要材料的一览。
