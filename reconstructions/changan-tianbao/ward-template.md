# 里坊资料汇编目录模板

[天宝长安项目入口](README.md) · [通用史料手册](handbook/README.md)

本文件是各坊资料汇编的共用目录与标注规范，不记录某一坊的具体内容。各坊按本模板组织资料；具体条目、出处和结论写在各自的坊文件中。

## 一、用途与范围

- 适用于唐长安各里坊的资料整理与复原说明。
- 统一章节、字段、分级、编号和空值写法，便于横向比较。
- 不规定建模参数，也不替任何一坊补默认尺寸。
- 各坊可有不同材料密度，但结构保持一致；没有内容的章节写“本坊无”或“已查未见”。

## 二、设计原则

1. **同构可比**：所有坊使用同一套顶层结构和字段名。
2. **模块可裁**：核心必写，扩展模块按材料启用。
3. **证据优先**：每条信息有出处、有等级、有推导强度。
4. **空值一致**：“空”“未见”“已排除”在所有坊中含义相同。
5. **编号可引**：坊码 + 模块 + 序号，支持跨坊引用。
6. **标准共用**：分级、字段、术语、引用格式只在本文件定义一次。

## 三、目录结构

## 四、模块启用表

每坊在正文前放一张表，说明哪些模块启用、哪些不适用。不启用也要写理由，避免读者误以为漏写。

| 模块 | 启用条件 | 不启用时 |
| --- | --- | --- |
| B1 宗教建筑 | 有寺、观、祠、塔、院 | 写“本坊无”或“已查未见” |
| B2 宅第 | 有宅第、赐第、旧宅、寄居记载 | 同上 |
| B3 官署与机构 | 有官署、进奏院、市署、驿 | 同上 |
| B4 市场与商业 | 有市、店、作坊、行业 | 同上 |
| B5 园林与池苑 | 有园、池、亭、庭院植被 | 同上 |
| B6 军事与空地 | 有球场、营、仓场、废宅 | 同上 |
| B7 生活与风俗 | 有人群、活动、文学材料 | 同上 |
| B8 专题研究 | 有跨对象争议或复原问题 | 可省略，并在 A4 说明 |

## 五、详条字段

每个对象按以下十项展开，长短随材料而定，但不缺项。总表可以简略，详条不简略。

| 序号 | 字段 | 写什么 | 没有依据时 |
| --- | --- | --- | --- |
| 1 | 标识 | 名称、别名、类型、编号 | — |
| 2 | 直接记载 | 原文短引、出处、年代、关系类型、方位精度 | 写“本址无直接记载” |
| 3 | 人物与年代 | 官品、爵位、任职时间、天宝时是否可见 | 分项留空 |
| 4 | 制度背景 | 营缮令、品级、宅第制度；注明年代差 | 写“无可用制度条文” |
| 5 | 同类参照 | 同城、同时、同等级、同功能；逐条写可借与不可借 | 写“已查，未见合适参照” |
| 6 | 推导 | 分条结论，每条标强度 | 可省略，但不得补数字 |
| 7 | 分布 | 院界、院数、轴线、相邻关系 | 写“本址无院界/院数记载” |
| 8 | 大小 | 院宽深、开间、进深、柱高、台基、墙、屋顶 | 逐项写“本址无” |
| 9 | 材质与植被 | 墙材、瓦色、铺地、庭院花木 | 逐项留空 |
| 10 | 不能证明与待查 | 明确列出不能证明什么、下一步查什么 | 至少写“不能证明具体尺寸与布局” |

## 六、证据与推导的标注

### 6.1 证据分级

| 级 | 能证明 | 不能证明 |
| --- | --- | --- |
| 甲 | 某建筑或宅第在坊内的具体方位、门街关系 | 院界、开间、尺寸 |
| 乙 | 某人与此坊有居住、卒地关系 | 具体宅第、产权、位置 |
| 丙 | 文本提到坊名或坊内地名 | 居住、产权、位置 |
| 丁 | 无有效关联或不可用 | — |

- 孤证不等于低；只要原文明确，仍按甲或乙。
- 矛盾记载并列，不合并、不取一、不互相校正。
- 丙、丁材料进附录，不进主表。

### 6.2 推导强度

| 强度 | 含义 |
| --- | --- |
| 较可能 | 有直接前提，且有同城或同类参照支持 |
| 备一说 | 有前提，但存在竞争解释，不能定为一说 |
| 仅可排除 | 只能否定某说法，不能正面推定 |

- 身份只能推出“等级区间”，推不出具体尺寸。
- 制度只作上限，不作实际。
- 同类参照给入口，不直接抄数字；不跨级、不链式。
- 没有参照时写“已查，未见”，不拿相似建筑顶替。

### 6.3 引用与转引

| 标记 | 含义 |
| --- | --- |
| 直接 | 引自原文、发掘报告或图版 |
| 转引（已核） | 二手材料给出引用，且已核对原书或原报告 |
| 转引（未核） | 二手材料给出引用，尚未核对原件 |
| 待核 | 只有转述，找不到引用或暂时无法核对 |

- 二手材料只要给出引用，可以照录，但必须保留其引用链。
- 不引百科或自媒体本身，只引它指向的原始材料；找不到原始材料时标“待核”。
- 引用格式统一到卷次、条目、页码、图版号或遗迹编号。

### 6.4 方位精度

| 精度 | 含义 |
| --- | --- |
| 坐标 | 有测绘或考古坐标 |
| 隅 | 只知在某隅 |
| 门街 | 某门之东/西/南/北，某街之北/南 |
| 相邻 | 某宅次北、某寺之东等相对关系 |
| 仅坊 | 只知在坊内 |
| 无 | 方位未记 |

只记录到原文的精度，不补足。图上留白是正式表达。

### 6.5 空值

| 写法 | 含义 |
| --- | --- |
| 空 | 该项不适用或原文未记 |
| 未见 | 已查，未见 |
| 已排除 | 有材料，但经核对不可用 |

## 七、编号

- 坊码用 2–4 个字母，例如 `PK`、`AR`、`CR`。
- 模块号固定为 `B1`–`B8`；新增模块从 `B9` 起，不插号、不重排。
- 对象编号：`{坊码}-{模块}-{序号}`，例如 `PK-B2-01`。
- 跨坊引用只写对象编号，不写页码。
- 条目内字段用固定名称，便于并表和检索。

## 八、适配规则

1. **核心不删**：A 段每坊必写；没有内容写“本坊无”或“已查未见”。
2. **模块可裁**：至少有一个对象才启用；不启用要在模块表中说明。
3. **不强行对称**：没有的就不写，不拿类比填满。
4. **不重复定义**：分级、字段、术语只在本文件定义，各坊直接引用。
5. **不横比强求**：各坊材料密度不同，空值也是比较信息。
6. **新增模块**：放在 B 段末尾，并在修订记录中说明。

## 九、跨坊共用层（可选）

若需要跨坊比较，可另建以下共用件，不放进各坊正文：

- `ward-comparison.csv`：只抽关键字段，如坊面积、门数、街巷、寺观数、宅第数、机构、市场、证据等级分布。
- `ward-index.md`：各坊文件、编号前缀与主要材料的一览。
- 共用术语表和引用格式仍以本文件为准。

## 十、维护

- 修改分级、字段或空值规则，会影响所有坊文件；修改前先在本文件记录，再逐坊更新。
- 各坊不得自行另立一套分级或字段；确有需要，先改本模板。
- 本模板只定义“怎么写”，不评价某一坊的具体结论。
