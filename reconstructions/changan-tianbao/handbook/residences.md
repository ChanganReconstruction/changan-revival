# 住宅与宅第

| 资料类别 | 所见材料与限度 |
| --- | --- |
| **RS-01 里坊院落遗迹** | 布政坊发现院落墙、水井及水缸，见报告图二 [S01](sources.md#s01)。这些遗迹体现生活设施与院落的相邻关系；不是普通民居完整平立面，也不自动确定居住者身份。 |
| **RS-02 官员宅第记载** | 《长安志》平康坊条对褚遂良宅、王志愔宅等多以坊门和街道定位；记宅主和方位不等于记载宅界、开间、屋顶或同一时点的居住情况 [S07](sources.md#s07)。 |
| **RS-03 高等级宅第个案** | 安仁坊西南隅宅邸遗址见多个相连院落、房址、部分廊道、散水与排水沟；高等级为发掘者对规模等的判断，不能视作所有官宅通式 [S03](sources.md#s03)。 |

可核的院落和房址平面尺寸见[尺度参考](dimensions.md#courtyards)；没有实测的开间、进深和高度不要补成史料。先搭体块时可用[体块缺省值](dimensions.md#defaults)，并标为展示假设。

## 等级制度不是宅第实测

《唐会要》卷三十一元和十二年（817）奏文引《营缮令》有“三品已上，堂舍不得过五间九架” [S04](sources.md#s04)。这是比天宝晚的奏文所引的**规制参照**，不能单凭它把天宝某位官员的宅第定成五间；“架”也不可当成九个进深开间或直接换算成米数。官号、爵位只能作为选择参考类型的线索，特殊赐第、旧宅沿用或后改道观另行判断。

《开天传信记》称李林甫在“正堂后别创一堂”，叙其有“却月之形” [S08](sources.md#s08)。这条笔记提供前后关系和弯曲形象，未给尺寸，也未说月形具体指平面、屋面还是其他部位。

## 通用宅第院落类型参考

具体宅第只有方位、没有院落构成时，可用 [H1–H3 类型参考](residence-types.md) 补空间骨架：

| 类型 | 院落 | 用途 |
| --- | --- | --- |
| H1 | 一进院 | 地块较小或材料只支持单院 |
| H2 | 两进院 | 两进院建模参照 |
| H3 | 多院式 | 三进主院或带东西侧院的大型多院宅第 |

类型参考默认满配，具体项目有反证才减项；补足部分必须标为类型参考，不能写成某宅史料。该参考不以李林甫宅为依据，也不按官品硬绑。
