# 唐长安街巷与建筑形制手册

[天宝长安项目入口](../README.md) · [平康坊专项](../pingkang/README.md)

**收录范围：天宝年间（742—756）长安及可用于对读的唐代资料。**

本手册整理文献记载、遗址、实物和图像；资料条目不规定建模方法，也不给没有史料依据的默认尺寸。参照物不一定与天宝同年，也不一定在同一坊；条目注明资料对象与证据限度。项目方案、占位尺寸与资产交付见[平康坊专项](../pingkang/README.md)。

需要给缺失院落补空间骨架时，使用[宅第院落类型参考（H1–H3）](residence-types.md)；该文是项目建模参考，不属于史料条目，也不把类型补足写成某宅史实。

要搭整栋建筑、院落组群或坊市，先看[建模图版索引](modeling-references.md)：按空间尺度找整体外观、剖面和能读出道路与院落关系的总平面。外部图版保留在来源站点，索引提供图号或题注；零散构件和器物按下表查相应主题。

需要查道路、城墙、院落和房屋的可核尺寸，见[尺度参考](dimensions.md)；该页只列有出处的数值和量取口径，并在缺项时给出一组标明为展示假设的体块缺省值。

## 如何读条目

- **文献记载**说明原文所述关系、制度或活动，区分当时记载与后世追述。规制上限不等于某座建筑的实际规格。
- **考古与实物**说明遗址、测量对象和尺寸口径。房基存留不等于屋顶已知；单一遗址的实测不等于全城通例。
- **图像与类比**区分原图、解释性复原图和后世现状。异地或较晚的唐代实物可以对读，不当作天宝长安某一建筑的原貌。
- **未见依据**直说未知，不用项目默认数字补成史实。`ST`、`RS` 等仅是资料索引编号，不是历史分类或制作模板。
