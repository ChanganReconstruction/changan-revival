# 城市边界与城门

外郭城、皇城、宫城、里坊和市场的边界涉及不同空间。城门遗址所存门道、墩台、墙基，与文献所载门楼及当代保护建筑不是同一类证据。

| 条目 | 所见材料与限度 |
| --- | --- |
| **CE-01 外郭城墙与城壕** | 城址考古汇编收录郭城、城墙与城门材料；明德门保护资料同时涉及门、墙、壕，但现代展示设计不能作为唐代实测断面 [S18](sources.md#s18)。现有条目不支持把局部墙材或壕段状态推广到全城。 |
| **CE-02 外郭城门** | 明德门为外郭南正门。朱雀大街五桥并列遗址的中桥与明德门中央门道在中轴线上相对，见考古所报道 [S02](sources.md#s02)。该关系不说明其他门的门道数或上部门楼形态。 |
| **CE-03 皇城门与宫门** | 含光门相关调查见城址考古汇编 [S18](sources.md#s18)；大明宫丹凤门见发掘资料 [S14](sources.md#s14)。二者分属不同空间，且各有遗址分期。 |
| **CE-04 坊门、宅门与市门** | 安仁坊北墙有角门和门外涵洞，详见 [ST-04](streets.md#st-04)；宅门与街道文字关系见 [ST-05](streets.md#st-05)；东市门数见《长安志》，详见 [MK-01](markets.md#mk-01)。 |
