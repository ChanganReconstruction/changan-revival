# 生活器物与图像

本页供整体布局确定后查器物和人物。搭整栋建筑或坊市时，从[建模图版索引](modeling-references.md)进入。

| 条目 | 所见材料与限度 |
| --- | --- |
| **SCN-01 门前与街巷设施** | 布政坊图二见院落墙、井、水缸；安仁坊角门与西市分别提供涵洞、桥板等实例 [S01](sources.md#s01)、[S02](sources.md#s02)、[S13](sources.md#s13)。这些是各处遗迹，不证明每一院门都有同样设施。 |
| **SCN-02 庭院、厅堂与织物** | 晚唐《北里志》记花卉、怪石盆池、垂帘及茵榻帷幌；盛唐韩休墓《乐舞图》《山水图》另提供人物及景物图像 [S11](sources.md#s11)、[S26](sources.md#s26)。两类材料都不能提供某处天宝宅院的完整陈设。 |
| **SCN-03 器用与货物** | 布政坊出土碗、盆等见简报图二〇 [S01](sources.md#s01)；何家村窖藏见精工金银器个案 [S27](sources.md#s27)。国博藏平康坊出土鎏金银茶托高4厘米、口径17.4厘米；同出器物有860年纪年铭，是晚唐对照，不是天宝陈设 [S09](sources.md#s09)。器形与出土地可查，不据此确定室内摆放或普通民居的配备。 |
| **SCN-04 人物、车马与音乐** | 国博藏鲜于庭诲墓陶俑有胡人骑驼、骆驼载乐等形象 [S28](sources.md#s28)。可观察姿态、衣物与驮具；葬俑的尺寸和釉色不等于活体、织物的尺度和颜色。 |
