# 地形、水系与园林

| 条目 | 所见材料与限度 |
| --- | --- |
| **LS-01 塬坡、台地与地面** | 含元殿遗址材料涉及龙首塬地貌、殿台与前庭，见 [S15](sources.md#s15)。历史地层、台基顶与现代地表是不同标高口径。 |
| **LS-02 街沟、桥板与涵洞** | 布政坊 `L1` 见道路及路沟；安仁坊角门外见砖砌涵洞；西市有石板桥及涵洞材料，分见 [S01](sources.md#s01)、[S02](sources.md#s02)、[S13](sources.md#s13)。三例各有遗址与位置，不能合称一种通用断面。 |
| **LS-03 城市渠系、水井与缸** | 布政坊发掘简报图二有院落墙、井、水缸；汉唐昆明池水系勘探报告的书目见 [S19](sources.md#s19)。前者是坊内局部，后者为大型水系，两者不能证明一条具体坊街的沟、井与干渠相通。 |
| **LS-04 池苑、岸线与小庭园** | 大明宫太液池为皇家池苑，遗址有专门发掘 [S19](sources.md#s19)；晚唐《北里志》记南、中二曲有花卉，部分有怪石、盆池 [S11](sources.md#s11)。两者规模和性质不同；今遗址公园岸线也不等于全段唐代岸线。 |
