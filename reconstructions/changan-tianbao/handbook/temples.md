# 佛寺与道观

塔、经幢与郊坛另见[礼制与纪念建筑](ritual.md)。盛唐敦煌净土变呈现殿、廊、台基的视觉层次 [S05](sources.md#s05)，不是长安某寺的测绘图。南禅寺与佛光寺是山西的唐代木构个案，均晚于天宝 [S06](sources.md#s06)。

| 类型 | 所见材料与限度 |
| --- | --- |
| **TP-01 佛寺与佛殿** | 西明寺东部考古揭示局部院落、东院墙与道路；相关研究讨论建筑柱网与营造尺 [S29](sources.md#s29)。该院的发掘范围不能代表全寺。 |
| **TP-02 食堂与附属堂屋** | 《寺塔记》记平康坊菩提寺食堂东壁吴道玄画，另记大佛殿内槽北壁郑法士旧画 [S07](sources.md#s07)。功能与墙面位置有据，食堂大小、门位和院落次序不明。 |
| **TP-03 钟楼** | 《寺塔记》称平康坊菩提寺因李宅在东而把钟楼置于西。此为个案，不能由此得出钟楼层数，也不能推出西楼必与鼓楼成对 [S07](sources.md#s07)。 |
| **TP-04 道观与舍宅置观** | 《长安志》记嘉猷观由李宅东南一隅划出；《唐会要》卷五十另载永穆公主天宝七载舍宅置观 [S07](sources.md#s07)、[平康坊引文 PK-S07](../pingkang/README.md#pk-s07)。改变用途不等于史料已说明保留或重建了哪些房屋。 |
