# 建筑构件与地表

先看屋顶、柱列、台基和入口在整体中的关系，见[建模图版索引：整栋建筑](modeling-references.md#roofs)；构件细部按下文查出处。墙基、台基和柱高的可核数值见[尺度参考](dimensions.md#heights)。

| 条目 | 所见材料与限度 |
| --- | --- |
| **CP-01 屋面与瓦** | 布政坊发掘简报图三十五有陶筒瓦；南禅寺大殿为单檐歇山的唐代木构实例，建中三年（782） [S01](sources.md#s01)、[S06](sources.md#s06)。出土瓦件不单独决定原建筑屋顶，现存佛殿也不是天宝宅第通例。 |
| **CP-02 柱网、梁架与斗栱** | 西明寺东部院落研究讨论柱网与营造尺；南禅寺（782）和佛光寺东大殿（857）保留晚于天宝的地上构造 [S06](sources.md#s06)、[S29](sources.md#s29)。遗址柱位、研究推算与现存梁架是不同类型的证据。 |
| **CP-03 坊墙、宅墙与台基** | 安仁坊北墙角门、布政坊院落墙和含元殿台基分属坊墙、院墙和宫殿遗址 [S01](sources.md#s01)、[S02](sources.md#s02)、[S15](sources.md#s15)。不见全城通用的墙高、厚度、表面颜色或包砖比例。 |
| **CP-04 门窗、匾额与隔断** | 平康坊嘉猷观有赐额记载，《北里志》有小堂垂帘的描写 [S07](sources.md#s07)、[S11](sources.md#s11)。有额、有帘不说明其开口尺度、匾额截面或所有宅院的门窗形式。 |
| **CP-05 铺地、散水与排水** | 安仁坊宅邸见散水和排水沟，布政坊见道路、沟、墙、井 [S01](sources.md#s01)、[S03](sources.md#s03)。这些局部遗存不能证明整坊铺地材料一致。 |
| **CP-06 植被与器用** | 见[生活器物与图像](scene.md)，其中区分文献、墓葬图像和出土实物。 |
| **CP-07 院廊** | 安仁坊报道记录部分院落由长廊相接；盛唐敦煌净土变有殿、台基与回廊的建筑图像 [S03](sources.md#s03)、[S05](sources.md#s05)。两者不构成统一的跨距、屋檐或廊形规则。 |
| **CP-08 台阶与入口高差** | 含元殿发掘涉及殿台与前庭，安仁坊角门考古涉及门外水渠及涵洞 [S02](sources.md#s02)、[S15](sources.md#s15)。宫殿台地与坊门跨沟可见于不同遗址，宅门普遍门槛高度仍不可定。 |
