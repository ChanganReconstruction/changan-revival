# 尺度参考：城、街、院、房

[手册入口](README.md) · [资料索引](sources.md) · [建模图版索引](modeling-references.md)

本页先回答“有没有可核的数值、这个数量的是什么”，不替项目规定某座建筑该取多少。数值来自考古勘查、发掘简报或可核研究；同一对象有不同口径时分别列出，不取平均。把这里的数字套到另一坊、另一座建筑之前，先确认量取对象和年代是否对应。

另在[体块缺省值](#defaults)给出一组只用于先搭体块的起点值。那组数不是史料，不用于考证图，也不能写成“唐代通例”；有本址数据时立即替换。

## 怎么用

1. **先看量取对象。** 路土宽、路沟宽、墙到墙的用地宽不是一回事；墙基宽、墙顶宽和墙高也不是一回事；通面阔和单间面阔同样要分清。
2. **再看证据层级。** 本页按“考古实测—同址文献或规制—异地唐构比例—展示假设”排列。层级越低，越不能写成该对象的史实。
3. **缺项就留空，或改用体块缺省值。** 没有实测的房屋高度、墙顶和门楼，不拿“常见值”补成史料；需要先搭体块时，用[体块缺省值](#defaults)，并在模型、图纸和说明中标注“展示假设”，写明用了哪一行。

## 体块缺省值（展示假设）

本节只解决“资料缺项时先搭一个可替换体块”的问题，不是唐长安的统计平均值，也不是制度规定。数值是项目暂定的起点，方便街道、院落和房屋先有相对关系；有本址实测、文献尺度或测绘时，应逐项替换。用于考证图、复原图或交付说明时，必须标“展示假设”，并写明用了哪一行、替换了什么。

**统一模数。** 缺省值中的“间”按 **1 间 = 3.5 米**换算。这是项目展示模数，不是唐尺；H1–H3 类型图的 60 图面单位 = 1 间也按此接入，换算见[宅第院落类型的米制桥](residence-types.md#metric-bridge)。

<a id="terms"></a>

## 术语

| 术语 | 在本手册里的意思 | 常见误用 |
| --- | --- | --- |
| 面阔 | 建筑正面的宽度；可以说通面阔，也可以说单间面阔 | 不说明是总宽还是单间，数字就无法比较。 |
| 进深 | 建筑前后方向的深度；同样分通进深和单间进深 | 把进深当成开间数，或把“架”当成进深米数。 |
| 间 | 相邻柱或墙之间的开间单位，是数量 | “五间”不是五米，也不等于五个房间。 |
| 架 | 梁架或檩子的数量，主要表进深方向的构造 | 不是开间数，也不是可直接换算的进深。 |
| 椽 | 屋面基层的椽条 | 椽径、椽距不是斗栱材分。 |
| 举折 | 屋面从檐口到屋脊的升高与水平跨度之比 | 总举折不是每一架椽的坡度，也不能直接当屋顶角度。 |
| 收分 | 墙体或塔身向上逐渐收窄 | 收分不是倾斜角，也不是侧脚。 |
| 侧脚 | 柱脚外撇、柱头内倾的做法 | 侧脚不是收分，不能拿塔身收分代替。 |
| 材分 | 斗栱和木构的模数单位 | 唐构材分有研究推定，不能不加说明套到所有建筑。 |
| 营造尺 | 当时营造所用尺长 | 唐尺实物尺长有差异；294 毫米是西明寺研究的推定，不是全唐统一尺。 |

<a id="misuse"></a>

## 常见误用

| 常见说法 | 问题 | 应该怎么写 |
| --- | --- | --- |
| 朱雀大街宽 155 米 | 旧勘探口径可能含路沟或按不同边线；2023 年推算为约 127 米（不含路沟） | 同时写数值和口径，不取平均。 |
| 坊墙高 2.5–3 米 | 多数材料说的是墙基宽，墙高没有实测 | 写“基宽约 2.5–3 米”，高度留空。 |
| 唐长安城墙高约 5 米 | 常见的是据基宽、比例或后世城墙作的推算 | 写“原高未实测”，需要时标明是展示假设。 |
| 五间九架就是五间宽、九间深 | “架”是梁架/檩数，不是开间数，也不等于米 | 保留“五间九架”的原文，不擅自换算。 |
| 唐尺就是 30 厘米 | 实物尺长有差异，营造尺还要看地点和时期 | 说明用的是哪一把尺、哪个研究推定。 |
| 从敦煌壁画量出建筑尺寸 | 壁画有透视、缩放和画面组织，不能当测绘 | 只看殿、廊、台基的高低和遮挡关系。 |
| 南禅寺大殿可以当唐代住宅样板 | 它是 782 年山西佛殿，晚于天宝，功能和地域都不同 | 只借它的柱高与举折比例，并标明是类比。 |

<a id="gaps"></a>

## 还缺的数值

| 缺什么 | 影响 |
| --- | --- |
| 普通住宅的檐高、脊高、层高 | 可先用[体块缺省值](#defaults)搭体块；仍不能从现有资料得出“长安民居标准高度”。 |
| 坊墙原高、墙顶宽度和墙面包砌 | 可先用体块缺省值搭墙身，但墙基走向之外仍无实测。 |
| 城门楼、塔顶和塔刹原状 | 可先用[竖向占位](#default-vertical)做远景；门址和现存塔身不能补出上部结构。 |
| 各坊内部的宅地划分和道路密度 | H1–H3 的[米制桥](residence-types.md#metric-bridge)只能排类型；具体坊的宅地划分仍缺。 |
| 墙、瓦、木构的原色和彩画 | 现在只有[展示色](#default-materials)，不是原色样本，也不能据此判断彩画。 |
| 铺面的门扇、柜台、招幌和开闭方式 | 房址和敦煌图像各说明一部分，不能拼成完整立面。 |

数值和出处继续补时，先查原报告的量取对象，再决定是否收进本页；只有二手转述的，标“转引”或暂时不收。
