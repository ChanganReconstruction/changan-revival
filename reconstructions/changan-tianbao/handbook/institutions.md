# 公共设施、客舍与工坊

仓窖与窑址可查地下遗存与生产地点，但不能据此复原地上建筑；见[建模图版索引：整体参照缺口](modeling-references.md#gaps)。

| 条目 | 所见材料与限度 |
| --- | --- |
| **IN-01 官署** | 《长安志》记皇城、官署与门街等关系；《唐六典》记录机构的职官与职责，但不能从职掌直接推得院数与柱距 [S20](sources.md#s20)。 |
| **IN-02 留后院与进奏院** | 《长安志》平康坊条列进奏院；《演繁露》追述藩镇置邸与大历十二年（777）的改称 [S21](sources.md#s21)。后出的名录不等于750年名册，本条也未见可核实的统一平立面。 |
| **IN-03 学馆** | 《唐六典》卷二十一“国子监”载祭酒、司业、诸博士及学生等 [S20](sources.md#s20)。学官或学生人数不说明讲堂、斋舍等房间的数量。 |
| **IN-04 仓储** | 《唐六典》卷十九“司农寺”可查仓储管理；布政坊发现砖砌窖穴，见 [S01](sources.md#s01)、[S20](sources.md#s20)。砖砌窖穴是遗迹类型，仅凭形态不能判定为官粮仓。 |
| **IN-05 客舍与投宿** | 李永对《唐摭言》“客户坊”之说有专门考辨 [S22](sources.md#s22)。这些材料涉及驻留、游谒与投宿，不能认定成片旅舍，更未给客舍的具体楼层和格局。 |
| **IN-06 工坊与窑址** | 醴泉坊报告记录唐代残窑、灰坑与窑业遗物 [S23](sources.md#s23)。设施与生产堆积不说明全部作坊屋面、檐高或店铺和工场的相对布局。 |
