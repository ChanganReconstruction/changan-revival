# 唐长安建模图版索引

[手册入口](README.md) · [资料索引](sources.md)

先找**能搭出第一版体块或街区布局**的图。整栋建筑看轮廓、开间、台基和剖面；院落和坊市看道路、入口、院墙与屋址怎么接。遗址总图能回答这些关系就收；只见单件遗物或一截墙、不能帮助判断整体的图，不列在这里。按空间尺度查找，不必先知道遗址属于哪个坊。

图版保留在来源网站。存世建筑看的是调查或修缮后的形态；发掘图只画已揭露或可辨认的部分；壁画和研究复原用来比较形象或方案，不能与遗址拼成一套已证实的平、立、剖。下表注明每张图能回答的问题。

| 要搭什么 | 从哪看起 |
| --- | --- |
| 一栋殿堂或一座塔坛 | [整栋建筑](#roofs) · [塔与祭坛](#ritual) |
| 一组院落、寺院或宫殿 | [院落与组群](#courtyards) · [宫城与殿台](#palaces) · [水岸与宫苑](#landscape) |
| 一片坊市或一段城市边界 | [街与坊市](#streets) · [铺面与摊棚](#shops) · [全城与城门](#city) |
| 这类对象还缺什么图 | [整体参照缺口](#gaps) |

## 整体参照缺口

| 尚缺什么 | 当前能画到哪一步 |
| --- | --- |
| 普通住宅的整栋外观与院落完整平、立面 | 个别遗址能读出院界或部分房址，不支持把佛殿缩小当民居，也不能据此补齐普通宅院的屋顶、立面和进深。 |
| 连贯的长安市街立面和完整坊市总图 | 能读局部路、沟与相邻屋址；铺面图像只能类比，不应批量套成整条街的门面。 |
| 天宝城门上部、墙顶与塔顶 | 发掘图多只见下部；墓画里的阙楼与改建后的存世塔都不能替代实证。 |
| 仓署、学馆、客舍及工坊的地上建筑 | 仓窖排列、窑址分布有助于定位遗存，但不能给出地上房屋或完整院落，未列为整体建筑图版。资料见[公共设施与生产服务](institutions.md)。 |

局部资料没有丢弃：[资料索引](sources.md)保留原始报告与藏品出处。做到细部再按需从[通用构件](components.md)、[生活器物与图像](scene.md)或[地形、水系与园林](landscape.md)查，不必挤进整体建模的入口。
